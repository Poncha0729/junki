# Claude が ponchablog に直接投稿できるようにする設定

継続的に記事を投稿してもらうための、一度きりの設定手順です。

---

## 結論：WordPress の REST API を使う

理由は、これが唯一**「過去記事を読む」こともできる**方法だからです。

| できること | REST API | ブラウザ操作 |
|---|---|---|
| 新規記事の下書き作成 | ✅ | ✅ |
| **過去記事を読んでテンプレを再現** | ✅ | ✅ |
| **アフィリエイトタグを過去記事からコピー** | ✅ | ✅ |
| クラウド版(Web)から実行 | ✅ | ❌ |
| PCの電源が入っていなくても動く | ✅ | ❌ |
| 定期実行・自動化 | ✅ | ❌ |

REST API なら、Claude が自分で過去記事を読めるので、
**「テンプレ通りに書いて」が推測なしで実現できます。**

---

## 設定は3ステップ

### ステップ1：WordPress でアプリケーションパスワードを発行

1. 管理画面 → **ユーザー** → **プロフィール**
2. 一番下の **「アプリケーションパスワード」** セクション
3. 名前に `claude-post` と入れて「新しいアプリケーションパスワードを追加」
4. 表示される `xxxx xxxx xxxx xxxx` を控える（**この画面でしか見られません**）

> **セキュリティについて**
> - ログインパスワードとは**別物**です。これが漏れてもログインはされません
> - **いつでも失効**させられます（同じ画面から削除）
> - 心配なら、**投稿専用のユーザーを新規作成**して、権限を
>   「**編集者**」か「**投稿者**」にしてください。管理者権限は不要です

### ステップ2：Claude 側でネットワークを許可

**※ クラウド版(Web)を使う場合のみ必要。デスクトップ版なら不要です。**

1. **claude.ai/code** を開く
2. 使っている**環境（Environment）の設定**へ
3. ネットワーク／外部接続の許可リストに **`ponchablog.com`** を追加

> 参考：https://code.claude.com/docs/en/claude-code-on-the-web

### ステップ3：認証情報を環境変数に登録

同じ環境設定の**「環境変数（シークレット）」**に登録します。

| 変数名 | 値 |
|---|---|
| `WP_URL` | `https://ponchablog.com` |
| `WP_USER` | ログインID |
| `WP_APP_PASSWORD` | ステップ1で発行した文字列 |

> **チャットには貼らないでください。** 環境変数にしておけば、
> スクリプトが読むだけで、会話の履歴には残りません。

---

## ⚠️ 設定後は「新しいセッション」を開いてください

ネットワークの許可設定は**コンテナの起動時に読み込まれます。**
すでに動いているセッションには反映されないため、
**設定後に新しいセッションを開く**必要があります。

---

## 設定できたら、こう頼んでください

```
blog-drafts/fetch-wordpress-articles.py を実行して、
過去の住宅ローン記事を5本取得してください。

その内容からテンプレート（冒頭文・LINE誘導・ボックスのCSS・
アフィリエイトタグ）を読み取って、
blog-drafts/2026-09-20-housing-loan-3numbers.html を
完全に同じ型に整えてから、下書きとして投稿してください。
```

これで、推測ゼロの記事が出来上がります。

---

## 用意してあるスクリプト

| ファイル | 役割 |
|---|---|
| `fetch-wordpress-articles.py` | 過去記事を取得してテンプレート解析（色・CSSクラス・ショートコード・アフィリエイトリンク・LINEリンクを自動抽出） |
| `post-to-wordpress.py` | 記事を**下書き**として投稿（いきなり公開はしない） |

どちらも標準ライブラリのみ。追加インストール不要です。

### 動作確認（ご自身のPCで先に試せます）

Claude 側の設定をする前に、PCで動くか確認できます。

```bash
export WP_URL="https://ponchablog.com"
export WP_USER="あなたのログインID"
export WP_APP_PASSWORD="xxxx xxxx xxxx xxxx"

# 過去記事が読めるか確認
python3 fetch-wordpress-articles.py --ids 7014

# 読めたら、fetched-articles/ の中身を Claude に渡せば
# その時点でテンプレート再現が可能になります
```

**この確認だけでも、今すぐ状況が前に進みます。**
`fetched-articles/7014.html` をこのチャットに貼っていただければ、
ネットワーク許可を待たずにテンプレートを再現できます。

---

## デスクトップ版を使う場合

ネットワーク許可（ステップ2）は不要で、ステップ1と3だけで動きます。
あるいは **Claude in Chrome 拡張**を入れれば、
ログイン済みのブラウザをそのまま操作できるので、認証情報すら不要です。

ただし **PCが起動している必要**があり、定期実行には向きません。
