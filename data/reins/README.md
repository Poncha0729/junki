# 東日本レインズ Market Watch データ

首都圏（東京・神奈川・埼玉・千葉）の中古マンション・中古戸建住宅の成約・新規登録・在庫データ。
出典は公益財団法人 東日本不動産流通機構（東日本レインズ）。

| ファイル | 内容 |
|---|---|
| `market-watch-monthly.json` / `.csv` | 月例速報 2025年1〜6月度から抽出した月次データ（2024-01〜2025-06、4,113セル、long format） |
| `market-watch-notes.json` | 各月度レポートの本文解説文 |
| `annual-longterm.json` | 年報ベースの年次系列（中古マンション 2004〜2025年、中古戸建 2013〜2025年）。各点に出典URL付き |

## スキーマ（monthly）

`month`(YYYY-MM) / `property_type`(mansion=中古マンション, detached=中古戸建住宅) / `region` / `metric` / `basis`(value・yoy_pct・mom_pct) / `value` / `unit` / `source_report`(採用したレポート年月) / `revised`(レポート間で改定があった値)

region: 首都圏, 東京都, 東京都区部, 東京都多摩, 埼玉県, 千葉県, 神奈川県, 横浜市・川崎市, 神奈川県他, 札幌市, 仙台市
metric: 成約件数, 成約㎡単価, 成約価格, 成約専有面積, 成約土地面積, 成約建物面積, 成約築年数, 新規登録〜, 在庫〜

## 抽出と検証

`scripts/reins/` のスクリプトで PDF → テキスト（文字座標から行を再構成）→ 13ヶ月表のパース → tidy 化。
LLM による抽出・検証の結果と決定論パーサの結果を突合し、重複 3,656 セルが 100% 一致することを確認済み。

## 注意

- 数値は成約（契約成立）ベース。広告の売り出し価格とは異なる。
- ㎡単価×3.30579 で坪単価に換算できる。
- 年次系列は原典サイトへ直接アクセスできない環境で収集したため、顧客向け資料に使う際は原典の年報で最終確認すること。
