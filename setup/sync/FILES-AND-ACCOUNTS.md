# 2台のファイル・アカウント同期（Windows）

コードの同期は [SYNC.md](SYNC.md) に分けてあります。
こちらは**それ以外のファイルとアカウント**をどう2台でそろえるかです。

---

## 役割分担をまず決める

何を同期するかは、どちらのPCで何をするかが決まっていないと決められません。

| | 現PC（据え置き） | 新PC = X1 Yoga |
|---|---|---|
| 主な用途 | サブ。据え置きでの作業・確認 | **AIメイン**（Claude、生成・調査）＋日常作業 |
| 重い処理 | 避ける | **こちらに寄せる**（32GB） |
| 外出時 | 置いていく | **持ち出す**（タブレットモードで内見先へ） |
| 物件の横断メモ | 見るだけ | **こちらで編集** |

> 役割が違ってよいので、**全部を同じ状態にしようとしないこと**がコツです。
> 「両方で使うもの」だけを同期対象にします。

---

## 1. ファイルはどこに置くか

### 🚫 OneDrive に入れてはいけないもの

| 入れてはいけない | 理由 |
|---|---|
| **Git リポジトリ**（`dev/` 配下） | `node_modules` が数万ファイルあり同期が終わらない。`.git` が半端に同期されると**リポジトリごと壊れます** |
| ビルド生成物（`.next`, `build`, `dist`） | 毎回中身が入れ替わり、競合ファイルが量産される |
| 仮想マシン・ゲーム・大きなキャッシュ | 容量を食い切る |

### ✅ フォルダ構成の目安

```
C:\Users\<あなた>\
  dev\                     ← Git リポジトリ。OneDrive の外に置く
    junki\
  OneDrive\
    書類\
      物件\                ← 物件の横断メモ・資料PDF・内見写真
      契約\                ← 重要書類
    デスクトップ\
    ピクチャ\
  Downloads\               ← 同期しない（一時置き場）
```

**要点は `dev\` を OneDrive の外に置くこと**だけです。ここさえ守れば他は好みで構いません。

## 2. OneDrive の設定

Windows に最初から入っています。Microsoft アカウントでログインすれば使えます。

> **Windows のサインインがローカルアカウントでも使えます。**
> OneDrive アプリ側に Microsoft アカウントでサインインすれば同期は動きます。
> Windows のサインイン方法を変える必要はありません。
> （BitLocker の回復キーだけは Microsoft アカウントに預けられないため、
>   自分で保管します → [../new-pc/THINKPAD-X1-YOGA.md](../new-pc/THINKPAD-X1-YOGA.md)）

### 容量

無料枠は 5GB です。物件資料のPDFや内見写真が増えると足りなくなることがあります。
不足したら Microsoft 365 の契約（1TB付き）を検討してください。
**プランと容量は変わることがあるので、契約前に最新の内容を確認してください。**

### 「ファイル オンデマンド」を有効にする

全ファイルの実体をPCに持たず、開いたときだけダウンロードする設定です。
新PCのディスクを節約できます。

```
タスクバーの OneDrive アイコン → 歯車 → 設定
→ 同期とバックアップ → 詳細設定 → ファイル オンデマンド
```

### 同期するフォルダを選ぶ

両方のPCに全部を降ろす必要はありません。

```
OneDrive 設定 → アカウント → フォルダーの選択
```

現PCには「物件」フォルダだけ降ろす、といった使い分けができます。

## 3. アカウントの同期

**どのアカウントが何を運ぶか**を把握しておくと、移行時に迷いません。

| アカウント | 同期されるもの | 設定場所 |
|---|---|---|
| **Microsoft** | Windows の設定の一部、OneDrive のファイル | 設定 → アカウント |
| **Google** | Chrome のブックマーク・履歴・**開いているタブ**・パスワード | Chrome → プロフィール → 同期を有効にする |
| **GitHub** | コード（リポジトリ）、VS Code の個人設定（Settings Sync） | VS Code 左下の歯車 → Backup and Sync Settings |
| **Anthropic** | Claude の会話履歴 | Claude デスクトップでログイン |

> **これが「家で絞り込んで外で続きを見る」を成立させる土台です。**
> 2台とも同じ Google アカウントにしてください。
> 詳細は [../property/PROPERTY-SEARCH.md](../property/PROPERTY-SEARCH.md)。

### VS Code の設定について

2種類あるので混同しないでください。

- **個人設定**（テーマ・キーバインド・フォント）→ VS Code の **Settings Sync**（GitHubアカウント）
- **プロジェクト設定**（整形ルール・推奨拡張）→ **リポジトリの `.vscode/`**（Git で同期済み）

個人の好みをリポジトリに入れると相手のPCの見た目まで変わってしまうので、分けてあります。

## 4. アプリはどちらに入れるか

| アプリ | 現PC | 新PC | 備考 |
|---|---|---|---|
| Chrome | ✅ | ✅ | 同じ Google アカウントで |
| Claude デスクトップ | ✅ | ✅ | **AI作業は新PC中心** |
| VS Code | ✅ | ✅ | Settings Sync でそろう |
| Git / Node.js | ✅ | ✅ | `setup-windows.ps1` が入れます |
| OneDrive | ✅ | ✅ | Windows 標準 |
| PowerToys | — | ✅ | ウィンドウ整列。2画面運用で効きます |
| 重い生成系ツール | — | ✅ | 新PCに寄せる（32GB / 1TB） |

**「両方に入れる＝両方で同じ設定にする」ではありません。**
同期するのはアカウントに紐づくものだけで、十分です。

## 5. 手でコピーするもの（同期されません）

クラウド同期に乗らない／乗せてはいけないものです。**新PC構築時に1回だけ**移します。

| 対象 | 移し方 |
|---|---|
| `.env` / `.env.local` | パスワードマネージャーのセキュアノート経由（[SYNC.md](SYNC.md) §4） |
| 有料ソフトのライセンスキー | 同上 |
| 署名用の証明書・秘密鍵 | USBメモリで直接。**メールやチャットに貼らないこと** |
| ブラウザ拡張機能の個別設定 | 拡張ごとにエクスポート機能があれば使う。無ければ手で設定し直す |
| プリンタ・スキャナの設定 | 新PCで入れ直す |

> **メールやチャットに貼らないでください。** 履歴が半永久的に残り、
> 後から検索で掘り出されます。

## チェックリスト

- [ ] `dev\` フォルダが **OneDrive の外**にある
- [ ] OneDrive にログインし、「ファイル オンデマンド」が有効
- [ ] 物件フォルダを作り、両方のPCから開けることを確認した
- [ ] Chrome が 現PC・新PC の2台で同じ Google アカウント
- [ ] Chrome の同期項目に「開いているタブ」が入っている
- [ ] VS Code の Settings Sync が両PCでオン
- [ ] `.env` など手でコピーするものを移し終えた
- [ ] 現PCに未 push の変更が残っていない（`git status` がきれい）

最後の1つを忘れると、新PCに移った後で「あの変更どこ行った」になります。
