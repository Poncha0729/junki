# ThinkPad X1 Yoga Gen 7（32GB / 1TB）の設定

[setup/README.md](../README.md) の STEP 2 を実行したあとに読んでください。
汎用の手順では触れていない、**この機種だから必要な設定**をまとめています。

---

## この機種で効いてくる特徴

| 特徴 | 設定への影響 |
|---|---|
| **14型 2-in-1**（画面が360度回る） | タブレットモードで間取り図が見られる。回転ロックの設定が要る |
| **本体収納式のペン** | 物件資料PDFへの書き込みに使える。ペン設定は消さないこと |
| **タッチスクリーン** | 内見先での操作に効く |
| **Windows Hello**（指紋＋顔） | 持ち歩く機体なので必ず有効にする |
| **Thunderbolt 4** | ドック1本で外部ディスプレイ＋給電＋有線LAN |
| **メモリ 32GB** | AIメイン機として使うのに十分。重い処理はこちらに寄せる |
| **SSD 1TB** | 物件写真・資料を貯めても当面困らない |

## 1. 持ち歩く前提のセキュリティ（最優先）

外に持ち出す機体に**物件資料・契約書・パスワード**が入ります。
紛失・盗難時にそのまま中身を読まれない状態にしてください。

### ディスクの暗号化

この機体は **Windows 11 Pro** なので BitLocker を使います。

```
Win + R → control /name Microsoft.BitLockerDriveEncryption
→ C: の「BitLocker を有効にする」
```

ウィザードの設定は次で問題ありません。

| 項目 | 選ぶもの | 理由 |
|---|---|---|
| 暗号化する範囲 | **使用済み領域のみ** | 新品同様なら十分。速い |
| 暗号化モード | **新しい暗号化モード** | この機体から動かさないため |
| システムチェック | **実行する** | 起動不能になる事故を事前に検出できる |

#### 回復キーの保存先 ── ここが一番重要

**ローカルアカウントで Windows にサインインしている場合、「Microsoft アカウントに保存」は選べません。**
選ぶと「Microsoft アカウントにサインインできません」というエラーになります。
この機体はローカルアカウント運用なので、自分で保管します。

| 方法 | 備考 |
|---|---|
| **USBメモリに保存** | 暗号化するCドライブには保存できない仕様。USBが要ります |
| **印刷して紙で保管** | PCとは別の場所に置く。プリンタが無ければ PDF をUSB側へ |
| **パスワードマネージャーに控える** | 実運用ではこれが一番失くしにくい |

**最低2つでやってください。** USBメモリ1本だけに頼るのは危険です。

有効化したあとは、ドライブがロックされていない間いつでも取り出せます。

```powershell
(Get-BitLockerVolume -MountPoint 'C:').KeyProtector |
  Where-Object KeyProtectorType -eq 'RecoveryPassword' |
  Select-Object KeyProtectorId, RecoveryPassword
```

> **回復キーを失うと、ご自身でも二度と中身を取り出せません。**
> Microsoft アカウントに預ける場合と違い、ローカルアカウント運用では
> **管理責任が完全に自分にあります。**

#### 状態の確認

```powershell
Get-BitLockerVolume -MountPoint 'C:' |
  Select-Object VolumeStatus, ProtectionStatus, EncryptionPercentage
```

`ProtectionStatus` が `On` になっていれば有効です。
`EncryptionPercentage` は暗号化の進捗で、100 になるまでは裏で処理が続きます
（**待たずに次の作業に進んで構いません**）。

### Windows Hello と自動ロック

```
設定 → アカウント → サインイン オプション
→ 顔認識（Windows Hello）と 指紋認識 を両方登録
```

指紋は**手袋や濡れた手で失敗する**ので、顔認証と両方入れておくと外で困りません。

```
設定 → アカウント → サインイン オプション
→ 「しばらく操作しなかった場合に、Windows でサインインを要求する」→ 1分
```

カフェで席を立つ場面を想定して短めにしてください。

## 2. Lenovo Vantage は消さないでください

プリインストールの中で**これだけは残す**必要があります。

- **BIOS とドライバの更新経路**がここしかありません
- **バッテリーの充電しきい値**を設定できます
- 保証状況の確認もここです

広告的な通知は出ますが、消すと更新手段を失います。
通知が邪魔なら `Vantage → 設定 → 通知` で個別にオフにできます。

### バッテリーをいたわる設定（据え置き時間が長い場合）

自宅で電源につなぎっぱなしにする時間が長いなら、満充電で止めない設定にします。

```
Lenovo Vantage → デバイス → 電源
→ 「バッテリー充電しきい値」を有効にし、上限 80% 程度に設定
```

外出前日に解除すれば満充電にできます。**常に持ち歩くなら設定不要**です。

## 3. ペンとタッチを物件探しに使う

2-in-1 である利点が一番出るのがここです。

### 間取り図や物件資料への書き込み

物件資料はPDFで渡されることが多く、**Chrome や Edge のPDFビューアには手書き機能がありません。**
書き込むなら次のどちらかです。

| 方法 | 向いている場面 |
|---|---|
| **Microsoft Edge** のPDF表示 → 「描画」 | その場でさっと丸を付ける。追加インストール不要 |
| **OneNote** に貼って書き込む | 物件ごとにページを分けて残す。帰宅後に現PCからも見られる |

OneNote に寄せると、[FILES-AND-ACCOUNTS.md](../sync/FILES-AND-ACCOUNTS.md) の
OneDrive 同期にそのまま乗ります。物件探しの全体の流れは
[property/PROPERTY-SEARCH.md](../property/PROPERTY-SEARCH.md) にまとめてあります。

### モードの切り替え

- 画面を360度回すと自動でタブレットモードになります
- 回転してほしくない場面（膝の上で使うなど）は
  `通知領域（Win + A）→ 回転ロック` で固定できます
- ペンは本体に挿すと充電されます。抜くとペアリングされ、
  ボタンからアプリを呼び出せます（`設定 → Bluetooth とデバイス → ペンと Windows Ink`）

## 4. このPCをAIメインにする

**AI作業はこの新PC側をメインにします。** 32GB / 1TB なので性能面の制約はありません。

| | 現PC（据え置き） | 新PC = X1 Yoga |
|---|---|---|
| 主な用途 | サブ・確認用 | **AIメイン**＋日常作業＋持ち出し |
| 重い処理 | 避ける | こちらに寄せる |

成果物は**必ず GitHub 経由**で現PCに渡してください（[SYNC.md](../sync/SYNC.md)）。
画面を見ながら直接コピペすると履歴が残りません。

### AIメイン機が持ち出し機でもある、という点に注意

この構成だと、**一番よく使うPCを毎日外に持ち出す**ことになります。
据え置きのAI機とは前提が変わるので、3点だけ意識してください。

#### ① 電力と発熱

AI作業は負荷が高く、バッテリーの減りが速くなります。

- 外で長時間やるなら**電源の確保**（カフェのコンセント、モバイルバッテリーはUSB-C PD対応のもの）
- **外出前日に充電しきい値を解除**して満充電にする（§2 参照）
- 膝の上や布の上で使うと**吸排気を塞いで性能が落ちます**。硬い面に置くか、タブレットモードなら発熱面を確認しながら

#### ② 扱うデータが外に出る

AIに投げた内容はこのPCに残ります。そのPCを持ち歩くので、
**§1 のディスク暗号化と自動ロックは必須**です。省略しないでください。

契約書や物件資料をAIに読ませる場合は特に、紛失時の影響が大きくなります。

#### ③ 回線

**外でAIを使うにはネット接続が要ります。** Wi-Fi のない場所では動きません。

- スマホのテザリングを設定しておく（接続手順を一度試しておくこと）
- 内見先で使う可能性があるなら、通信量の目安も把握しておく

### 入れておくAI関連ソフト

`setup-windows.ps1` と拡張機能リストで導入されます。

| ソフト | 導入方法 | 状態 |
|---|---|---|
| Claude デスクトップアプリ | winget `Anthropic.Claude` | スクリプトに含まれています |
| VS Code 拡張 `anthropic.claude-code` | `setup/dotfiles/vscode-extensions.txt` | 同上 |

CLI 版を使いたい場合は公式ドキュメント（<https://code.claude.com/docs>）を参照してください。
導入方法が変わることがあるため、ここには固定のコマンドを書いていません。

## 5. 1TB の使い分け

パーティションは分けず、**1つのCドライブのままで構いません。**
分けると片方だけ容量不足になり、後から調整するのが面倒です。

代わりにフォルダで分けます（[FILES-AND-ACCOUNTS.md](../sync/FILES-AND-ACCOUNTS.md) 参照）。

```
C:\Users\<あなた>\
  dev\          ← Git リポジトリ。OneDrive の外
  OneDrive\     ← 書類・物件資料・内見写真
  Downloads\    ← 一時置き場。定期的に空にする
```

OneDrive の「ファイル オンデマンド」を有効にしておけば、
1TB を使い切る心配はまずありません。

## 6. 外部ディスプレイとドック

Thunderbolt 4 なので、**ケーブル1本で映像・給電・有線LAN**がまとまります。

- ドックは Lenovo 純正でなくても Thunderbolt 4 対応であれば動きます
- 2画面にするなら PowerToys の **FancyZones** が効きます
  （`setup-windows.ps1` で導入済み）
- 画面ごとの拡大率が違うとアプリがぼやけることがあります
  → `設定 → システム → ディスプレイ → 拡大縮小` を画面ごとに調整

## 7. プリインストールの判断表

[cleanup/CLEANUP.md](../cleanup/CLEANUP.md) の一般論に加えて、ThinkPad 固有の判断です。

```powershell
# まず何が入っているか見る（何も消えません）
.\setup\cleanup\cleanup-windows.ps1
```

メーカー独自アプリは**削除候補に含めず「要判断」として一覧表示**されます。
以下を参考に判断してください。

| アプリ | 判断 | 理由 |
|---|---|---|
| **Lenovo Vantage / Commercial Vantage** | ✅ **残す** | BIOS・ドライバ更新の唯一の経路 |
| **Lenovo Utility / Hotkeys** | ✅ **残す** | Fnキー・特殊キーが効かなくなる |
| **ペン関連の設定アプリ** | ✅ **残す** | ペンが使えなくなる |
| **Dolby Access / Dolby Audio** | ⚠️ 残す方が無難 | 音質調整。消すと音が変わることがある |
| **Glance by Mirametrix**（視線追跡） | 🔸 使わないなら消してよい | 常駐して起動が遅くなる |
| **Lenovo Now / 各種お試しアプリ** | 🔸 消してよい | 広告枠 |
| **McAfee / Norton 体験版** | ✅ **消す** | Defender を無効化したまま期限切れになる。下記参照 |

> 上の一覧は一般的な構成に基づくものです。**実機に何が入っているかは個体差がある**ので、
> スクリプトの出力と照らし合わせて判断してください。
> 判断に迷うものがあれば、名前を教えていただければ調べます。

### 体験版セキュリティを消したあとの確認

McAfee や Norton の体験版を消したら、**必ず Defender が有効に戻ったか確認**してください。

```
設定 → プライバシーとセキュリティ → Windows セキュリティ
→ 「ウイルスと脅威の防止」が緑のチェックになっていること
```

体験版が入ったままだと Defender が無効化され、期限切れ後は**どちらも守ってくれません。**
