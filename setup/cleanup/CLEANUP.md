# 不要ソフトの整理

新PCに最初から入っている「使わないソフト」を減らして、起動と動作を軽くします。

---

## 方針：まず見る、次に選ぶ、最後に消す

用意したスクリプトは **既定では一覧を表示するだけで、何も削除しません。**
プリインストールの整理は元に戻しにくい操作を含むため、
「候補の提示」と「実際の削除」を意図的に分けてあります。

```bash
# Windows — まず見る（何も消えません）
.\setup\cleanup\cleanup-windows.ps1

# Windows — 見た上で、1件ずつ確認しながら消す
.\setup\cleanup\cleanup-windows.ps1 -Remove

# macOS — 棚卸し（表示のみ。削除は手動）
bash setup/cleanup/cleanup-macos.sh
```

---

## 🚫 消してはいけないもの

| 分類 | 例 | 消すとどうなるか |
|---|---|---|
| ランタイム | Microsoft Visual C++ 再頒布可能パッケージ、.NET Runtime/Desktop Runtime | **他のアプリが起動しなくなる**。複数バージョンが並んでいるのは正常です |
| OSの基盤 | Microsoft Store、Windows セキュリティ、アプリ インストーラー(winget) | 復旧が非常に面倒。winget を消すとセットアップスクリプトも動きません |
| ドライバ／制御ソフト | Intel/AMD/NVIDIA グラフィックス、タッチパッド、指紋認証、電源管理 | **画面・入力・バッテリー制御が壊れます**。OEM製でも消さないこと |
| メーカー製の更新ツール | Lenovo Vantage、Dell Update、HP Support Assistant、MyASUS | BIOS・ドライバ更新の経路を失います。**広告は出ますが残す方が安全** |
| macOS | Apple 純正アプリ全般 | 再インストールに OS 再インストールが必要になる場合があります |

> **迷ったら消さない。** 容量に困っていないなら、残しておくコストはほぼゼロです。

---

## ✂️ 消してよいもの（判断の目安）

### 1. ゲーム・エンタメのプリインストール

Candy Crush、Solitaire Collection、Disney+、TikTok、Spotify（プリイン版）など。
これらは**OEMが広告枠として入れているもの**で、消してもOSに影響しません。

### 2. 期限切れのセキュリティ体験版（McAfee / Norton）

**これは優先的に消してよい枠です。** 理由:

- Windows には標準で **Windows セキュリティ (Defender)** が入っており、個人利用には十分です
- 体験版が入っていると Defender が**自動で無効化**され、体験版の期限が切れると
  **どちらも十分に働かない状態**になります
- 常駐して起動を遅くし、「契約を更新してください」の通知を出し続けます

削除後、`設定 → プライバシーとセキュリティ → Windows セキュリティ` を開いて
**「ウイルスと脅威の防止」が緑のチェックになっている**ことを必ず確認してください。

### 3. 使っていない常駐ソフト

一番効くのは削除ではなく **自動起動を切ること**です。

- Windows: `Ctrl + Shift + Esc` → タスクマネージャー → **スタートアップ アプリ** タブ → 不要なものを「無効化」
- macOS: システム設定 → 一般 → **ログイン項目**

「無効化」なら**いつでも戻せる**ので、削除より先にこちらを試してください。

### 4. 重複しているブラウザ／ツール

Chrome を使うなら、プリインストールの別ブラウザは消してかまいません。
ただし **Microsoft Edge は Windows の一部**として組み込まれており、
完全な削除はトラブルのもとです。使わないならタスクバーから外すだけにしてください。

---

## おすすめの順番

1. **スタートアップの無効化**（戻せる・効果が一番大きい）
2. **体験版セキュリティの削除**（Defender を正常に戻す）
3. **ゲーム・広告枠アプリの削除**（容量が空く）
4. それでも気になるものがあれば個別に判断

3まで終われば、体感速度はだいたい改善します。

---

## 整理のあとに確認すること

- [ ] Windows セキュリティが「保護されています」になっている
- [ ] Wi-Fi・Bluetooth・音量・画面の明るさが操作できる（ドライバを消していない証拠）
- [ ] 指紋認証／顔認証が使える（使っている場合）
- [ ] `.\setup\new-pc\verify-windows.ps1`（または `verify-macos.sh`）が全部 OK
- [ ] `npm run verify` が通る

最後の2つが通れば、開発環境は壊れていません。
