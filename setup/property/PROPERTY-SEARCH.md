# 物件探しの環境づくり（PC2台構成）

外で見つけた物件を、帰宅後に家のPCで続けて検討できる状態にするための設定です。

---

## 構成：タブレットは使いません

**ThinkPad X1 Yoga Gen 7 は 2-in-1（画面が360度回る）**なので、
外出先ではこれをタブレットモードで使います。専用のタブレットは不要です。

```
┌──────────────────┐        ┌──────────────────┐
│  現PC（据え置き）   │        │  X1 Yoga（持ち出し）│
│  サブ・確認用       │◀──────▶│  AIメイン・内見先   │
│                    │ Chrome  │  タブレットモード    │
└──────────────────┘  同期    └──────────────────┘
```

### タブレットを使わない方が楽な理由

| タブレットを足す場合 | X1 Yoga で完結する場合 |
|---|---|
| 端末が増える分、同期の設定が必要 | **同じPCなので同期が不要** |
| 物件サイトのお気に入りが端末ごとに分かれる | 分かれない |
| PDFの書き込みアプリを別に用意する必要がある | ペンでそのまま書ける |
| 充電するものが増える | 増えない |

**同期しなくていいものは、同期しないのが一番確実です。**

---

## 1. Chrome を2台でそろえる

同期が必要なのは **現PC ↔ X1 Yoga** の2台だけです。

両方の Chrome で**同じ Google アカウント**にログインし、同期をオンにしてください。

```
Chrome 右上のプロフィールアイコン → 「同期を有効にする」
→ 設定 → Google の設定と同期 → 同期する内容を管理
```

最低限オンにしておくもの:

- ブックマーク
- 履歴
- **開いているタブ** ← 「現PCで絞り込んだ物件を、出先で続きから見る」ができます
- パスワード

### 現PCで開いていたタブを X1 Yoga で開く

```
Chrome の ⋮ → 「他のデバイス」 → 現PC名 → 開いていたタブが一覧で出る
```

家で候補を10件ほど開いておいて、内見先でその続きを見る、という流れが作れます。

---

## 2. 物件サイトのアカウントを作る

主要な物件ポータル（SUUMO / LIFULL HOME'S / アットホーム など）は、
**ログインしていないと「お気に入り」が端末内保存**になります。

2台で同じお気に入りを見たいなら、**アカウント作成は必須**です。

### 登録前に確認すること

サイトごとに仕様が違うので、次を確認してから使うサイトを絞ってください。

| 確認すること | なぜ重要か |
|---|---|
| お気に入りがアカウントに紐づくか（端末内保存でないか） | 端末内だと2台で共有できません |
| 保存できる件数に上限があるか | 上限が小さいと検討の途中で入らなくなります |
| 検索条件そのものを保存できるか | 毎回条件を入れ直す手間がなくなります |
| 新着通知（メール）があるか | 良い物件は動きが速いので取りこぼしを防げます |

### パスワードの管理

不動産会社ごとにアカウントが増えて管理できなくなりがちです。
**Chrome のパスワードマネージャー**に保存すれば、2台とも自動入力されます。

```
Chrome → 設定 → 自動入力とパスワード → Google パスワード マネージャー
```

## 3. 横断メモを1か所だけ作る

サイトをまたぐと「どこで見た物件か」が分からなくなります。**集約先を1つに決めてください。**

新PCが Windows なので **OneDrive 上の1ファイル**が素直です
（[../sync/FILES-AND-ACCOUNTS.md](../sync/FILES-AND-ACCOUNTS.md)）。

記録する項目の例:

| 項目 | 例 |
|---|---|
| 物件名 | ○○マンション 302 |
| 最寄駅・徒歩 | ○○駅 徒歩8分 |
| 家賃＋管理費 | 12.5万 + 8千 |
| 初期費用 | 敷1礼1 |
| 間取り・面積 | 1LDK / 42㎡ |
| **URL** | **必ず貼る** |
| 見た日 | |
| 感想 | 日当たり◎ / 線路の音が気になる |

> **URL は必ず貼ってください。** スクリーンショットだけ残すと、
> 後から「これどこの物件だっけ」となって探し直しになります。

## 4. 内見のときに効く準備

X1 Yoga を持ち出す前提の準備です。

### ペンで間取り図に書き込む

物件資料はPDFで渡されることが多いですが、
**Chrome のPDFビューアには手書き機能がありません。** 次のどちらかを使ってください。

| 方法 | 向いている場面 |
|---|---|
| **Microsoft Edge** でPDFを開く → 「描画」 | その場でさっと丸を付ける。追加インストール不要 |
| **OneNote** に貼って書き込む | 物件ごとにページを分けて残す。現PCからも見られる |

OneNote に寄せると OneDrive 同期にそのまま乗るので、帰宅後に現PCで続きを見られます。

### タブレットモードへの切り替え

- 画面を360度回すと自動で切り替わります
- 膝の上で使うときなど回転してほしくない場面は
  `Win + A → 回転ロック` で固定できます
- ペンは本体に挿すと充電されます

### そのほか

- **地図にピンを立てる** — Google マップで「保存」しておくと2台から同じリストが見られます。内見のルート組みが楽です
- **写真は物件ごとにまとめる** — 撮った直後に分けないと後で判別できません
- **バッテリー** — 外に出る前日は充電しきい値を解除して満充電に
  （[../new-pc/THINKPAD-X1-YOGA.md](../new-pc/THINKPAD-X1-YOGA.md)）
- **のぞき見** — 契約情報を扱うので、自動ロックは1分にしておいてください

## やりがちな失敗

| 失敗 | 対策 |
|---|---|
| ログインせずにお気に入り登録 → 現PCで見られない | 最初にアカウントを作る |
| スクショだけ撮って物件が特定できない | URL を横断メモに必ず貼る |
| サイトごとにパスワードが増えて管理不能 | Chrome のパスワードマネージャーに集約 |
| 各サイトのお気に入りがバラバラで比較できない | 横断メモを1か所に決める |
| 内見先でバッテリーが切れる | 前日に充電しきい値を解除して満充電 |
