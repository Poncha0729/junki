# 外出先のタブレットから駅・物件情報を見られるようにする

外出中にタブレットで物件・駅エリアを調べる、という使い方のための設定です。

---

## 前提：`localhost:3000` は外からは見えません

開発サーバ（`npm run dev`）が出す `http://localhost:3000` は、
**そのPCの中だけ**で通じるアドレスです。外出先のタブレットからは絶対に開けません。

やり方は2通りあり、**用途が違います**。

| | 方法A: Vercel に公開 | 方法B: 同一Wi-Fi内でLAN公開 |
|---|---|---|
| **外出先から見られる** | ✅ はい | ❌ いいえ |
| 自宅で見られる | ✅ はい | ✅ はい |
| PCの電源 | **切っていてOK** | **つけっぱなし必須** |
| 反映の速さ | push から約1分 | 即時（編集が即反映） |
| 用途 | **外出先での閲覧（本命）** | 自宅でのスマホ表示確認 |

外出先で使いたいので、**方法A が本命**です。方法B は開発中の確認用です。

---

## 方法A ── Vercel に公開する（外出先で使う本命）

所要 10分。**1回設定すれば、以後は `git push` するだけで自動更新されます。**

### A-1. Vercel にサインアップ

1. https://vercel.com/signup を開く
2. **「Continue with GitHub」** を選ぶ（GitHubアカウントでログイン）
3. 個人利用なら **Hobby プラン（無料）** を選択

### A-2. このリポジトリを取り込む

1. ダッシュボードで **「Add New…」→「Project」**
2. リポジトリ一覧から **`poncha0729/junki`** を選んで **「Import」**
   - 一覧に出ない場合 →「Adjust GitHub App Permissions」でこのリポジトリへのアクセスを許可
3. 設定はそのままで大丈夫です（Next.js は自動検出されます）

   | 項目 | 値 |
   |---|---|
   | Framework Preset | Next.js（自動） |
   | Build Command | `npm run build`（自動） |
   | Output Directory | `.next`（自動） |
   | Install Command | `npm install`（自動） |

4. **「Deploy」** を押す → 2〜3分でビルドが終わります

### A-3. URL を確認する

`https://junki-xxxx.vercel.app` のような URL が発行されます。
**この URL をタブレットで開けば、外出先でも見られます。**

> **補足：公開範囲について**
> この URL は**リンクを知っていれば誰でも見られる状態**です。
> 身内だけに限定したい場合は、Vercel のプロジェクト設定
> `Settings → Deployment Protection → Vercel Authentication` を有効にすると、
> Vercel にログインしたアカウントだけに制限できます。

### A-4. 以後の更新

```bash
git push
```

これだけです。push するたびに Vercel が自動でビルドし直し、同じURLが更新されます。

## 方法B ── 同一Wi-Fi内で見る（自宅での表示確認用）

自宅で「タブレットだと見た目がどうなるか」を確認したいときに使います。

### B-1. PCで LAN 向けに起動する

```bash
npm run dev:lan
```

（`setup` で追加済みのスクリプトです。`next dev -H 0.0.0.0` 相当）

### B-2. PCのローカルIPアドレスを調べる

```bash
# Windows
ipconfig | findstr IPv4

# macOS
ipconfig getifaddr en0
```

`192.168.x.x` のような値が出ます。

### B-3. タブレットのブラウザで開く

```
http://192.168.x.x:3000
```

**つながらないときは:**

- タブレットとPCが**同じWi-Fi**につながっているか確認（ゲスト用SSIDだと通りません）
- Windows のファイアウォールが 3000番を塞いでいる可能性 →
  `.\setup\new-pc\setup-windows.ps1 -OpenLanPort` を実行（確認プロンプトが出ます）
- macOS: システム設定 → ネットワーク → ファイアウォール で node の着信を許可

## タブレットのホーム画面に追加する（アプリとして使う）

毎回ブラウザでURLを打たなくて済むようにします。

このアプリは **Web アプリマニフェスト**（`src/app/manifest.ts`）を持っているため、
ホーム画面に追加すると単なるブックマークではなく**アプリとして開きます**:

- 専用アイコンが付く（iPad・Android の両方に対応したアイコンを同梱済み）
- アドレスバーが消えて全画面で表示される（`display: standalone`）
- 起動時の背景色・テーマ色がブランド色に揃う

> アイコンを変えたくなったら `scripts/generate-icons.py` の配色や形を編集して
> `python3 scripts/generate-icons.py` を実行すれば再生成できます（外部ライブラリ不要）。

<details>
<summary><b>iPad（Safari）</b></summary>

1. Safari で Vercel の URL を開く
2. 下部（または右上）の**共有ボタン**（□に↑）をタップ
3. **「ホーム画面に追加」** をタップ
4. 名前を「EKICHO」などにして「追加」
</details>

<details>
<summary><b>Android タブレット（Chrome）</b></summary>

1. Chrome で Vercel の URL を開く
2. 右上の **︙** をタップ
3. **「ホーム画面に追加」** をタップ
4. 名前を付けて「追加」
</details>

## 外出先での使い方

1. タブレットのホーム画面のアイコンをタップ
2. 駅を選ぶ → その駅の家賃相場・出口情報・周辺スポットが見られます
3. 気になった駅があれば、帰宅後に現PCで Claude に調べさせる

> **今の中身について（正直な状態）**
> 駅データ（`src/lib/stations.ts`）は現時点で**サンプルデータ**です。
> 駅の写真（`public/images/stations/...`）もまだ置かれていないため、
> 写真枠は空のまま表示されます（アプリのアイコンは別途用意済みで、こちらは表示されます）。
> 実際の物件情報を載せるには、このデータの拡充が別途必要です。
> 「どの駅を、どの情報で増やすか」が決まれば、そこから作業できます。
