# 外出先のタブレットで物件を探す

新PC（Windows）とタブレットを組み合わせて、
**外で見つけた物件を家のPCで続けて検討できる**状態にするための設定です。

---

## 結論から：要点は3つだけ

1. **各物件サイトで必ずアカウントを作ってログインする**
   → ログインしないと「お気に入り」が端末の中だけに保存され、PCから見られません
2. **タブレットとPCで同じ Chrome アカウントにログインする**
   → ブックマーク・開いているタブ・パスワードが両方で共有されます
3. **横断メモを1か所だけ作る**
   → サイトをまたぐと比較できなくなるため、集約先を1つに決めます

この3つを最初にやっておくと、「外で見た物件が家のPCで出てこない」が起きません。

---

## 1. ブラウザを揃える（ここが要）

新PCが Windows なので、**Chrome で揃えるのが一番素直**です。

### 新PC（Windows）側

`setup-windows.ps1` で Chrome は導入済みです。起動して Google アカウントでログインし、
**同期をオン**にしてください。

```
Chrome 右上のプロフィールアイコン → 「同期を有効にする」
→ 設定 → Google の設定と同期 → 同期する内容を管理
```

最低限オンにしておくもの:

- ブックマーク
- 履歴
- **開いているタブ**（これが「PCで見ていた物件をタブレットで開く」を可能にします）
- パスワード

### タブレット側

<details>
<summary><b>iPad の場合</b></summary>

**Safari のままだと Windows とは同期できません。** App Store から Chrome を入れてください。

1. App Store で「Chrome」を検索してインストール
2. Chrome を開き、**PCと同じ Google アカウント**でログイン
3. 同期をオンにする

Safari も併用して構いませんが、物件探しは Chrome 側に寄せてください。
</details>

<details>
<summary><b>Android タブレットの場合</b></summary>

標準で Chrome が入っています。

1. Chrome を開く → 右上の ⋮ → 設定
2. **PCと同じ Google アカウント**でログイン
3. 「同期を有効にする」
</details>

### 「PCで開いていたタブをタブレットで開く」

```
Chrome の ⋮（またはタブ一覧） → 「他のデバイス」
→ PC名をタップ → 開いていたタブが一覧で出る
```

家で絞り込んでおいて、外で続きを見る、という流れが作れます。

---

## 2. 物件サイトのアカウントを作る

主要な物件ポータル（SUUMO / LIFULL HOME'S / アットホーム など）は、
**ログインした状態でないと「お気に入り」が端末内保存**になります。

外出先のタブレットで保存した物件を家のPCで開きたいなら、**アカウント作成は必須**です。

### 使うサイトを決めるときの確認ポイント

サイトごとに仕様が違うので、登録前に次を確認してください。

| 確認すること | なぜ重要か |
|---|---|
| お気に入りがアカウントに紐づくか（端末内保存でないか） | これが端末内だと、そもそも2台で共有できません |
| 保存できる件数に上限があるか | 上限が小さいと、比較検討の途中で入らなくなります |
| 検索条件そのものを保存できるか | 毎回条件を入れ直す手間がなくなります |
| 新着通知（メール/プッシュ）があるか | 良い物件は動きが速いので、通知があると取りこぼしません |
| タブレットのブラウザで問題なく使えるか | アプリ専用機能があるサイトもあります |

> **アプリとブラウザ、どちらを使うか**
> アプリの方が動作は軽いことが多いですが、**PCとの行き来を考えるとブラウザで揃える方が混乱しません。**
> まずブラウザで使ってみて、不便ならアプリを足す、の順をおすすめします。

### パスワードの管理

不動産会社ごとにアカウントが増えて管理できなくなりがちです。
**Chrome のパスワードマネージャーに保存**しておけば、PC・タブレットの両方で自動入力されます。

```
Chrome → 設定 → 自動入力とパスワード → Google パスワード マネージャー
```

---

## 3. 横断メモを1か所だけ作る

サイトをまたぐと「どこで見た物件か」が分からなくなります。
**集約先を1つだけ決めてください。**

### おすすめ：OneDrive 上の1ファイル

新PCが Windows なので OneDrive が標準で入っています。
タブレットにも OneDrive アプリを入れれば、同じファイルを両方から編集できます。

記録する項目の例:

| 項目 | 例 |
|---|---|
| 物件名 | ○○マンション 302 |
| 最寄駅・徒歩 | ○○駅 徒歩8分 |
| 家賃＋管理費 | 12.5万 + 8千 |
| 初期費用 | 敷1礼1 |
| 間取り・面積 | 1LDK / 42㎡ |
| URL | （必ず貼る。後で辿れなくなるため） |
| 見た日 | |
| 感想 | 日当たり◎ / 線路の音が気になる |

> **URL は必ず貼ってください。** スクリーンショットだけ残すと、
> 後から「これどこの物件だっけ」となって探し直しになります。

### 代わりにスプレッドシートでもよい

Google スプレッドシートなら、タブレットのブラウザからそのまま編集できて
OneDrive アプリを入れる必要がありません。使い慣れている方で構いません。

---

## 4. 内見のときに効く準備

- **地図にピンを立てる** — Google マップで物件を「保存」しておくと、
  PC・タブレット両方から同じリストが見られます。内見のルート組みが楽になります
- **写真は物件ごとにまとめる** — 撮った直後にアルバム分けしないと後で判別できません
- **オフライン地図** — Google マップで該当エリアをダウンロードしておくと、
  電波の悪い建物内でも地図が使えます
- **モバイルバッテリー** — 地図と写真でバッテリーの消耗が速いです

---

## やりがちな失敗

| 失敗 | 対策 |
|---|---|
| ログインせずにお気に入り登録 → PCで見られない | 最初にアカウントを作る |
| スクショだけ撮って物件が特定できない | URL を横断メモに必ず貼る |
| iPad で Safari を使い、Windows と同期できない | iPad にも Chrome を入れる |
| サイトごとにパスワードが増えて管理不能 | Chrome のパスワードマネージャーに集約 |
| 各サイトのお気に入りがバラバラで比較できない | 横断メモを1か所に決める |

## チェックリスト

- [ ] 新PC の Chrome で Google アカウントにログインし、同期がオン
- [ ] 同期項目に「開いているタブ」が含まれている
- [ ] タブレットの Chrome が同じ Google アカウントでログイン済み
  （iPad の場合は Chrome をインストール済み）
- [ ] 「他のデバイス」からPCのタブが見えることを確認した
- [ ] 使う物件サイトのアカウントを作成し、両方の端末でログインした
- [ ] お気に入りに1件入れて、**もう片方の端末から見えることを確認した**
- [ ] 横断メモの置き場所を決めて、1件目を記入した
- [ ] Google マップで物件を「保存」できることを確認した

最後から3番目の「もう片方の端末から見えることを確認」が一番重要です。
ここを確かめずに進めると、内見が終わってから共有できていないことに気づきます。
