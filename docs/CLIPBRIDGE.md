# ClipBridge — PC とスマホで文字をやり取りする

PC のキーボードで打った文字をスマホに送る、スマホでコピーした文字を
PC のクリップボードに入れる、ための小さなツールです。
**スマホにアプリを入れる必要はありません。** ブラウザで URL を開くだけなので、
iPhone でも Android でも同じように使えます。

```
┌────────────┐   同じ Wi-Fi    ┌────────────┐
│    PC      │ ─────────────→ │   スマホ    │  PC のキーボードで打った文字が
│ npm run    │                │  ブラウザで  │  リアルタイムで映る → 「コピー」で
│ clipbridge │ ←───────────── │  URL を開く  │  スマホのどのアプリにも貼り付け
└────────────┘                └────────────┘
   スマホから送った文字は、そのまま PC のクリップボードに入る（Ctrl+V するだけ）
```

## 使い方

### 1. PC で起動する

```bash
npm run clipbridge
```

こう表示されます（アドレスと `?t=` の後ろは PC ごとに違います）。

```
  ClipBridge が起動しました

  PC で開く   : http://localhost:8787/?t=3f9a1c
  スマホで開く: http://192.168.1.23:8787/?t=3f9a1c
              : http://x1yoga.local:8787/?t=3f9a1c

  合言葉（?t=）: 3f9a1c  （tools/clipbridge/.token に保存。作り直すには --new-token）
```

`?t=` の合言葉は初回起動時に作られ、`tools/clipbridge/.token` に保存されて
次回以降も同じものが使われます。スマホのブックマークや iPhone のショートカットが
起動のたびに壊れないようにするためです。このファイルは `.gitignore` 済みで、
PC ごとに別のものになります。

「スマホで開く」の2行目の `PC名.local` は、Wi-Fi ルータが IP アドレスを
割り当て直しても変わらない URL です。ブックマークにはこちらを使ってください。

Windows の場合、初回だけ「Windows セキュリティの重要な警告」（ファイアウォール）が
出ます。**プライベート ネットワーク**にチェックを入れて「アクセスを許可する」を
押してください。`npm run dev:lan` のときと同じです。

### 2. PC でページを開く

「PC で開く」の URL をブラウザで開きます。**必ず `localhost` の方を開いてください。**
ページが自分を「PC」だと判断するのは `localhost` で開いたときだけです。

ページの一番上に QR コードと「スマホで開く」URL が出ます。

### 3. スマホでつなぐ

スマホを **PC と同じ Wi-Fi** につなぎ、カメラで QR コードを読み取ります。
QR が出ない（PC がオフライン）ときは、URL をそのまま打ち込んでください。

これで両方の画面の右上が「● 接続中」になります。

**iPhone の場合**は、共有シートや背面タップから使えるショートカットも作れます。
ブラウザを開かずに「選んだ文字を PC へ」「PC でコピーした文字を iPhone へ」ができるので、
毎回使うならこちらの方が楽です。手順は [`CLIPBRIDGE-IPHONE.md`](CLIPBRIDGE-IPHONE.md)。

### 4. 使う

| やりたいこと | 操作 |
|---|---|
| PC のキーボードでスマホに文字を入力したい | PC のページで「スマホへ送る」欄に打つ。打った先からスマホの画面に映る。打ち終わったら「送る」（Ctrl+Enter）→ スマホで「コピー」→ 使いたいアプリに貼り付け |
| スマホでコピーした文字を PC に持っていきたい | スマホのページで「PC へ送る」欄に貼り付けて「送る」→ **PC のクリップボードに入る**ので Ctrl+V するだけ |
| PC でコピーした文字をスマホに持っていきたい | スマホのページで「PC のクリップボードを取り込む」→ 「コピー」 |
| 前に送ったものをもう一度使いたい | 「履歴」から「コピー」 |

履歴はサーバを止めると消えます（どこにも保存していません）。

## できないこと

- **スマホの他のアプリに直接キー入力することはできません。** ブラウザだけで
  できるのは「文字を届けて、コピーできる状態にする」までです。他のアプリへは
  貼り付けで持っていきます。
  スマホ側の入力欄に直接打ち込みたい場合は、専用アプリが必要です（下記）。
- 画像やファイルは送れません。文字だけです。
- 外出先から自宅の PC へ、のようにネットワークをまたいでは使えません。
  同じ Wi-Fi（または同じテザリング）の中だけです。

## 専用アプリでやる場合

ブラウザだけでは届かない「スマホのアプリに直接タイプする」までやりたいときは、
既製のアプリの方が向いています。

| スマホ | アプリ | できること |
|---|---|---|
| Android | **KDE Connect**（無料・Windows 版あり） | PC のキーボードでスマホに直接入力、クリップボード双方向同期、ファイル送信、通知の転送 |
| Android | **scrcpy**（無料） | スマホの画面を PC に映してマウス・キーボードで操作、クリップボード同期。USB か Wi-Fi |
| Android / iPhone | **Windows「スマートフォン連携」** | 通知・SMS・写真。Android の一部機種はアプリの画面操作も |
| iPhone | **KDE Connect（iOS 版）** | クリップボード送信とファイル共有はできるが、リモートキーボードは不可 |

iPhone は Mac 以外との連携が Apple 側で閉じられているため、
Windows から iPhone に直接タイプする方法はありません。
iPhone ではこの ClipBridge の「送る → コピー」が現実的な落としどころです。

## 設定

| 環境変数 / 引数 | 内容 |
|---|---|
| `CLIPBRIDGE_PORT=8788` | ポートを変える（既定 8787） |
| `CLIPBRIDGE_TOKEN=xxxx` | 合言葉を環境変数で指定する（`.token` より優先） |
| `npm run clipbridge -- --new-token` | 保存されている合言葉を作り直す（URL を知られた気がするときなど） |
| `npm run clipbridge -- --no-clipboard` | PC のクリップボードに触らない（画面に表示するだけ） |

合言葉（URL の `?t=`）が無いと何もできないようにしてあります。
同じ Wi-Fi にいる他人が勝手に PC のクリップボードへ書き込めないようにするためです。
公共の Wi-Fi では、合言葉入りの URL を人に見せないでください。

## 仕組み

- `tools/clipbridge/server.mjs` — Node.js 標準モジュールだけで書いた HTTP サーバ。
  依存パッケージはありません。
- `tools/clipbridge/index.html` — PC・スマホ共通の画面。1ファイル。
- PC → 相手への通知は Server-Sent Events、相手 → PC は普通の POST。
- iPhone のショートカット向けに、`GET /api/clipboard`（PC のクリップボードを
  そのまま返す）と `GET /api/latest`（最後に届いた文字を返す）がある。
  どちらも `text/plain` を返すので、ショートカット側で JSON を解く必要がない。
  `POST /api/send` は `text/plain` の本文も受け付ける。
- PC のクリップボードは OS 標準のコマンドで読み書きします。
  Windows は PowerShell の `Set-Clipboard` / `Get-Clipboard`（`clip.exe` は
  日本語が化けるので使いません）、macOS は `pbcopy` / `pbpaste`、
  Linux は `wl-copy` → `xclip` → `xsel` の順に試します。
- `http://` の LAN では `navigator.clipboard` が使えないので、スマホ側の
  「コピー」は `document.execCommand('copy')` にフォールバックします。
  それでもダメな端末では、文字を長押しして手でコピーしてください。
