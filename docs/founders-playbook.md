## はじめに ― この本の使い方

経営書を 100 冊読んでも経営者にはなれません。しかし、100 人の経営者が「何を考え、どこで賭け、どう間違え、どう立て直したか」を横に並べて見ると、**個人の性格や時代を超えて繰り返される型**が見えてきます。本書はその型を抽出し、最後にあなた自身の計画に落とし込むために書きました。

読み方は 3 通りあります。

1. **通読する**: 序章 → 第1〜6部 → 第7部 → 第8部の順に読むと、歴史→現代→自分、の流れで頭に入ります。
2. **人物から読む**: 気になる人物の章だけ読んでも成立するように、各章は「生い立ちと転機 / 経営マインド / 戦略の打ち手 / 失敗と教訓 / あなたへの問い」の同じ骨組みで書いています。
3. **実践編から読む**: いますぐ計画が欲しい人は第8部から読み、根拠が知りたくなったら人物章へ戻ってください。

各章末の「あなたへの問い」は飛ばさないでください。**本書の価値の半分は、その問いに自分の言葉で答える時間にあります。**

## 序章 ― 経営者に共通する 10 の原則

本書に登場する数十人を並べて最初に見えるのは、「性格は全員違うのに、やっていることの骨格は驚くほど似ている」という事実です。先に骨格を示しておきます。各原則の右に、代表的に体現している人物を添えました。

| # | 原則 | 一言でいうと | 体現者の例 |
|---|------|------------|-----------|
| 1 | **登る山を先に決める** | 目標が具体的だと、途中の判断が全部速くなる | 孫正義、似鳥昭雄、ベゾス |
| 2 | **顧客の側に立ち、業界の側に立たない** | 業界の常識は顧客にとっての不便であることが多い | 小倉昌男、中野優作、ジャック・マー |
| 3 | **信用を先に稼ぎ、お金は後から回収する** | 無料・先出し・透明化で「信用残高」を積む | 西野亮廣、渋沢栄一、ベゾス |
| 4 | **一点集中して、他を捨てる** | 「やらないこと」を決めるのが戦略 | ジョブズ、ポーター、柳井正 |
| 5 | **小さく試し、速く直し、当たったら一気に賭ける** | 仮説→実行→検証→仕組化 | 三木谷浩史、リーンスタートアップ、藤田晋 |
| 6 | **仕組みで再現する** | 属人的な成功を、組織が繰り返せる形にする | 松下幸之助、フォード、稲盛和夫 |
| 7 | **人を大切にすることが最も割に合う** | 従業員第一は感情論ではなく戦略 | 松下幸之助、ケレハー、ジャック・マー |
| 8 | **長期で考え、短期で動く** | 300年ビジョンと今日の電話の両方 | 孫正義、ベゾス、永守重信 |
| 9 | **正直で、開かれている** | 隠す会社は長く続かない | 稲盛和夫、ダリオ、中野優作 |
| 10 | **失敗を前提に設計する** | 一勝九敗でも、九敗で死なない賭け方をする | 柳井正、本田宗一郎、マスク |

10 の原則は互いに矛盾するように見える箇所があります（長期 vs 短期、一点集中 vs 多角化、慎重 vs 大胆）。実は、**優れた経営者は「どちらか」ではなく「どの局面でどちらを使うか」を知っている**のです。第7部でその使い分けを整理します。

# 第1部 日本の歴史に学ぶ

## 1-1 近江商人と「三方よし」 ― 日本型経営の原型

### 背景
江戸時代、近江（現在の滋賀県）を拠点に全国を行商して回った商人たちは、地元でない土地で商売をするために「よそ者でも信頼される仕組み」を必要としました。そこで磨かれたのが、後に「売り手よし・買い手よし・世間よし」の**三方よし**として整理される考え方です。

### 経営マインド
- **世間（社会）を顧客と同格に置く**: 目先の利益で地域の信用を失えば、次の行商ができない。長期の取引可能性そのものが資産。
- **始末（節約）と勤勉**: 「陰徳善事」、見られていないところでの正しさを重んじる。
- **薄利多売と分散**: 一つの商品・一つの土地に依存しない。

### 戦略の打ち手
- 行商から出店へ、出店から製造・金融へと**川上・川下へ拡大**（伊藤忠、丸紅、高島屋、西武、ワコールなど近江商人系の企業は多い）。
- 「のこぎり商い」: 行きに持って行った商品を売り、帰りに現地の産物を仕入れて持ち帰る。**往復のどちらも空にしない**。物流効率の思想は現代の EC やサプライチェーンに通じます。

### 現代への翻訳
ESG や「パーパス経営」は新しい概念ではなく、三方よしの再発見です。**世間よしは道徳ではなく、よそ者が市場に参入するための参入戦略**でした。この視点は、あなたが新しい業界に「よそ者」として乗り込むときにそのまま使えます。

### あなたへの問い
- あなたの事業で「世間」にあたるのは誰か。その人たちが、あなたを応援する理由は何か。

## 1-2 二宮尊徳 ― 「積小為大」と再建の技術

### 背景
1787年生まれ。没落した農家に生まれ、荒れ地を開墾して家を再興し、その手腕を買われて小田原藩や各地の農村（約600村と言われる）の財政・農村再建を指導しました。

### 経営マインド
- **積小為大**: 大きなことは小さなことの積み重ねでしか成し遂げられない。
- **分度**: 収入に見合った支出の枠を定めること。再建の第一歩は必ず「身の丈の確定」。
- **推譲**: 分度を守って生まれた余剰を、将来（自分）や他者（社会）に譲ること。
- **至誠・勤労**: 姿勢の話ではなく、再建を持続させるための条件として置いた。

### 戦略の打ち手
- 再建を引き受けるとき、まず**過去数十年の収支を洗い出し、平均収入を「分度」に設定**。そこから逆算して支出計画を立てる。今日でいうデューデリジェンスと予算統制。
- 農民の**やる気の設計**: 表彰や貸付で、真面目に働く人が報われる仕組みをつくった。
- **報徳仕法**という「型」を作り、他地域へ横展開した。属人的な再建ではなく再現可能な方法論にした点が経営者的です。

### 現代への翻訳
ターンアラウンド（再建）の基本は今も同じです。「まず出血を止める（分度）→ 余剰を将来投資へ（推譲）→ 小さな成功を積み上げる（積小為大）」。稲盛和夫の JAL 再建（後述）も、この順序でした。

### あなたへの問い
- あなたの事業の「分度」はいくらか。固定費は、最悪の月の売上でも払えるか。

## 1-3 渋沢栄一 ― 「論語と算盤」、資本主義に倫理を埋め込む

### 背景
1840年生まれ。農家から幕臣、明治政府の官僚を経て民間へ。第一国立銀行（1873年）を皮切りに、生涯で約500の企業の設立・経営に関わり、約600の社会事業にも関わったとされます。2024年から一万円札の肖像。

### 経営マインド
- **道徳経済合一説**: 利益追求と道徳は矛盾しない。むしろ道徳のない利益は続かず、利益のない道徳は広がらない。
- **合本主義**: 一人の大金持ちではなく、多くの人から資本を集めて事業を起こす。**株式会社という「仕組み」を日本に根付かせた**のが最大の功績。
- **私利より公益**: 財閥を作らなかった。自分の持ち株比率を上げるより、事業が世に広がることを優先した。

### 戦略の打ち手
- **インフラから着手**: 銀行、鉄道、紡績、ガス、保険、製紙…。産業のボトルネックになるインフラを先に整備し、その上で多数の産業が育つ土壌を作った。プラットフォーム戦略の元祖。
- **人材の育成と接続**: 商業教育（現・一橋大学など）に力を注ぎ、経営者同士を結ぶ場（東京商法会議所）を作った。**ネットワークそのものを事業資産と見た**。
- **民間外交**: 日米関係の改善に私費と時間を投じた。海外の信用も長期の事業基盤と見た。

### 失敗と教訓
- 関わった企業のすべてが成功したわけではありません。しかし、支配せず多くに関与するポートフォリオ的な関わり方が、結果として日本経済全体の底上げにつながりました。

### 現代への翻訳
- 「上場」の本質は渋沢の合本主義そのものです。**多くの人からお金を集め、その事業を社会のものにする**。上場を目指す人は、渋沢の「なぜ多くの人の資本で事業をやるのか」を自分の言葉で言えるようにしておくべきです。

### あなたへの問い
- あなたが上場したいのは「自分が大金持ちになるため」か、「事業を社会のものにするため」か。両方なら、その比率は。

## 1-4 岩崎弥太郎 ― 「政商」の攻めと、三菱を残した引き際

### 背景
1835年、土佐の地下浪人の家に生まれる。土佐藩の商務を担当したのち、明治初期に海運業で独立（1873年、三菱商会）。政府の御用を得て台湾出兵・西南戦争の軍事輸送を請け負い、短期間で日本の海運を制しました。

### 経営マインド
- **「船を沈めても人は沈めるな」** と伝わる、人材重視。
- **決断は速く、集中は徹底**: 海運で外国資本（P&O やパシフィック・メール）を相手に価格競争を仕掛け、撤退させた。
- **独裁的な経営**: 「三菱は岩崎家の事業である」と宣言し、意思決定を一点に集めた。速度の源泉であり、後の批判の源泉でもあった。

### 戦略の打ち手
- **国家の需要に張る**: 政府が必要とする輸送を担い、それを梃子に船舶と航路を獲得。
- **川下から川上へ**: 海運から、船の修理（造船）、燃料（炭鉱）、保険、倉庫、為替（金融）へと垂直統合。今日の三菱グループの原型。
- **競争が消耗戦になったら統合する**: 対抗馬の共同運輸との激しい競争の末、合併して日本郵船が誕生（弥太郎の死後）。**勝ちきれない競争は「統合」で終わらせる**という選択肢。

### 失敗と教訓
- 政府との近さは急成長をもたらしましたが、政変で一気に敵に回りました。**単一の顧客・後ろ盾への依存は、最大の成長要因であり最大のリスク**でもあります。

### あなたへの問い
- あなたの売上の何%が、上位1社（または1つのプラットフォーム）に依存しているか。

## 1-5 松下幸之助 ― 「水道哲学」と仕組みの経営

### 背景
1894年生まれ。9歳で丁稚奉公、学歴は小学校中退。1918年に松下電気器具製作所を創業。二股ソケット、自転車用ランプで基盤を築き、松下電器（現パナソニック）を世界企業に育てました。「経営の神様」と呼ばれます。

### 経営マインド
- **水道哲学（1932年）**: 水道の水のように、良い品を安く大量に供給して貧困をなくすのが産業人の使命。この年を「命知元年」と呼び、社員に使命を語った。**使命が先、事業はその手段**。
- **衆知を集める**: 自分は学がないと公言し、社員・取引先・顧客の知恵を集めることを経営の中核に置いた。
- **素直な心**: 私心や思い込みを外し、物事をあるがままに見ること。
- **ダム経営**: 資金・設備・人材に「ダム」のような余裕を持ち、環境変化に耐える。

### 戦略の打ち手
- **事業部制（1933年）**: 製品ごとに独立採算の事業部を置き、経営者を社内で大量に育てた。**分権と責任の明確化**。
- **販売網の構築**: 系列販売店（ナショナルショップ）を全国に張り巡らせ、流通を自社の資産にした。
- **週休二日制（1965年）や独自の福利厚生**: 「人を作る会社」。
- **PHP研究所（1946年）、松下政経塾（1979年）**: 事業を超えて、思想と人材を社会へ供給。

### 失敗と教訓
- 戦後の公職追放、1960年代の「熱海会談」（販売店の赤字が深刻化し、幸之助が全国の販売店主と3日間膝詰めで話し合った）など、危機のたびに現場に戻って対話することで立て直した。**危機のときこそ、経営者が最前線の顧客・パートナーと直接向き合う**。

### 現代への翻訳
- 事業部制は、後の京セラのアメーバ経営、サイバーエージェントの子会社群、リクルートの新規事業制度などに形を変えて受け継がれています。「小さな経営者をたくさん作る」は日本企業が得意とする成長の型です。

### あなたへの問い
- あなたの会社が世の中からなくなったとき、困る人は誰で、何に困るか。それが「使命」の言語化の出発点。

## 1-6 本田宗一郎 ― 「三つの喜び」と、技術と経営の二人三脚

### 背景
1906年生まれ。自動車修理工から出発し、1948年に本田技研工業を設立。二輪で世界一となり、四輪に参入、F1 で勝ち、アメリカで最も愛される日本車メーカーの一つを作りました。

### 経営マインド
- **三つの喜び**: 「買う喜び、売る喜び、創る喜び」。顧客・販売店・作り手の三者がそれぞれ喜ぶ事業でなければ続かない。
- **得手に帆あげて**: 人は得意なことで勝負すべき。自分の不得手（お金・組織）は藤沢武夫に全面的に任せた。
- **失敗を恐れない**: 「成功は99%の失敗に支えられた1%」。
- **現場・現物・現実**: 机上ではなく現場で考える。

### 戦略の打ち手
- **マン島 TT レース出場宣言（1954年）**: まだ弱小メーカーの段階で世界最高峰のレースに挑むと社内外に宣言し、1961年に優勝。**高い目標を先に公表して、技術と組織を引き上げる**。孫正義の「山を決める」に通じます。
- **スーパーカブ（1958年）**: 誰でも扱えるバイクを世界へ。アメリカでは「You meet the nicest people on a Honda」の広告で、バイク＝不良のイメージを覆した。**製品ではなく、製品の意味を変えた**。
- **CVCC エンジン（1972年）**: 米国の厳しい排ガス規制（マスキー法）に世界で最初に適合し、後発の四輪メーカーが米国で信用を得た。**規制を「制約」ではなく「差別化のチャンス」と見る**。
- **藤沢武夫との分業**: 技術は本田、経営は藤沢。互いの領域に口を出さず、1973年に同時に引退。**創業者の引き際まで設計した**稀有な例。

### 失敗と教訓
- 空冷エンジンへの固執で若手技術者と対立し、水冷への転換を受け入れざるを得なかった。**創業者の成功体験は、次の時代の足かせにもなる**。

### あなたへの問い
- あなたの「得手」は何で、「不得手」は誰に任せるか。その人はもう隣にいるか。

## 1-7 井深大と盛田昭夫 ― ソニー、「理想工場」から世界ブランドへ

### 背景
1946年、井深大（1908年生）が東京通信工業を設立し、盛田昭夫（1921年生）が参画。設立趣意書には「自由闊達にして愉快なる理想工場の建設」とあります。トランジスタラジオ、トリニトロン、ウォークマン、CD、プレイステーションと、世界に先駆ける商品を生み続けました。

### 経営マインド
- **井深**: 「他人のやらないことをやる」。人のまねをしない。技術者の心を燃やす目標を出す。
- **盛田**: 「市場は作るものだ」。市場調査で新しい商品は生まれない。**顧客が言葉にできない欲求を先に形にする**。
- **社名変更（1958年、ソニー）**: 世界で覚えられる名前へ。**創業12年で、日本国内での知名度を捨ててグローバル前提のブランドに賭けた**。

### 戦略の打ち手
- **盛田、家族でニューヨークへ移住（1963年）**: 米国市場を「出張で見る」のではなく「住んで理解する」。海外進出の要諦を体現。
- **ブランドを売らない判断**: 米国の大手からトランジスタラジオ 10 万台の OEM 発注（相手ブランド名で販売）を受けたが、盛田はこれを断り、自社ブランドにこだわった。**短期の大口より、長期のブランド資産**。
- **ウォークマン（1979年）**: 「録音できないテープレコーダーは売れない」という社内の反対を押し切って発売。**用途（歩きながら聴く）を発明した**。
- **グローバル・ローカライゼーション**: 世界を一つの市場と見つつ、各国に根を下ろす。盛田が使った造語。

### 失敗と教訓
- ベータマックスは技術で勝ってVHSに市場で負けました。**規格競争は「仲間の数」で決まる**。オープンにするか囲い込むかの判断は、製品の良し悪しとは別の戦略問題です。

### 現代への翻訳
- ソニーは「日本で勝ってから海外へ」ではなく、**創業初期から海外を前提にブランドと組織を作った**企業です。第8部の海外戦略で改めて参照します。

### あなたへの問い
- あなたの社名・サービス名は、英語圏の人が一度で発音でき、覚えられるか。

## 1-8 稲盛和夫 ― フィロソフィとアメーバ、「動機善なりや、私心なかりしか」

### 背景
1932年生まれ。1959年、27歳で京都セラミック（京セラ）を創業。1984年に第二電電（現 KDDI）を設立して通信自由化に挑み、2010年に経営破綻した日本航空（JAL）の会長に無報酬で就任、わずか2年余りで再上場（2012年）へ導きました。2022年没。

### 経営マインド
- **人生・仕事の結果 ＝ 考え方 × 熱意 × 能力**: 考え方だけがマイナスになりうる。能力や熱意が高くても、考え方が間違っていれば結果は大きなマイナス。
- **動機善なりや、私心なかりしか**: 第二電電の設立を決める前、半年間自らに問い続けたという言葉。
- **利他の心**: 「世のため人のため」は建前ではなく、判断が迷ったときの最終基準。
- **売上最大、経費最小**: 経営の原則は驚くほど単純で、それを全社員が理解し実行できるかが差になる。

### 戦略の打ち手
- **アメーバ経営**: 組織を 5〜10 人程度の小集団（アメーバ）に分け、「時間当たり採算」で全員が経営数字を見る。全社員が経営者意識を持つ仕組み。
- **京セラフィロソフィ**: 判断基準を明文化し、コンパ（飲み会）や勉強会で徹底的に共有した。**文化は「語り続ける」ことでしか根付かない**。
- **第二電電（1984年）**: 巨大な NTT に対し、「国民のために通信料金を安くする」という大義で参入。強者に挑むときは、**大義と、味方が増える構造**（トヨタ・ソニー等の出資、ユーザーの支持）を先に作った。
- **JAL 再建（2010〜）**: フィロソフィの導入と部門別採算制の徹底により、社員の意識を変えて黒字化。**再建は財務の前に、人の意識から**。

### 失敗と教訓
- フィロソフィは「押し付け」と受け取られれば逆効果になります。稲盛自身が身銭を切り、率先垂範することで説得力を持ちました。**制度は、トップの行動と一致していないと機能しない**。

### あなたへの問い
- あなたの会社の「判断基準」は文章になっているか。社員はそれを暗唱できるか。

## 1-9 小倉昌男 ― 宅急便、「サービスが先、利益は後」

### 背景
1924年生まれ。父が創業した大和運輸の2代目社長。法人向け大口輸送で経営が傾く中、1976年に個人向け小口配送「宅急便」を開始。業界の常識（個人宅配は儲からない）と、監督官庁（運輸省）の規制と戦い、日本の生活インフラを作りました。『小倉昌男 経営学』（1999年）は日本の経営書の古典です。

### 経営マインド
- **サービスが先、利益は後**: 密度が上がれば利益は後からついてくる。先に投資してサービス品質を作る。
- **全員経営**: 現場のドライバーを「セールスドライバー」と呼び、判断を委ねた。
- **論理で考える**: 「牛丼の吉野家」（メニューを一つに絞ることで効率を出す）や「ハブ・アンド・スポーク」から学び、事業構造を数理的に考えた。

### 戦略の打ち手
- **商品を一つに絞る**: 荷物のサイズ・料金・翌日配達という**単純で分かりやすい約束**にした。
- **密度の経済**: 一つのエリアで荷物が増えるほど1個当たりコストが下がる。だから最初は赤字でも面を取りに行った。
- **規制との戦い**: 路線免許が下りない地域について、運輸大臣を行政訴訟で訴えた。**顧客の利益のために、公然と体制と戦う**姿勢が世論を味方につけた。
- **大口の三越との取引を切る**: 収益の柱だった百貨店配送を、宅急便に集中するために自ら打ち切った。**集中には「捨てる」痛みが伴う**。

### 失敗と教訓
- 宅急便の初日の取扱個数は 11 個でした。**業界を変えるサービスは、最初は誰にも気づかれない**。

### 現代への翻訳
- 中野優作（第6部）の「業界の常識を疑い、顧客側に立つ」や、ベゾスの「顧客起点で先行投資」と構造が同じです。**業界を変える人は、業界の「儲からない」を「まだ誰も設計していない」と読み替える**。

### あなたへの問い
- あなたの業界で「それは儲からない」と言われている領域はどこか。なぜ儲からないと言われているのか、構造を説明できるか。

# 第2部 世界の歴史に学ぶ

## 2-1 アンドリュー・カーネギー ― 垂直統合と「富の福音」

### 背景
1835年スコットランド生まれ。貧しい移民の子として12歳で紡績工場で働き始め、電信技手、鉄道会社の幹部を経て鉄鋼業へ。カーネギー・スチールは世界最大の鉄鋼会社となり、1901年に J.P. モルガンへ約4億8千万ドルで売却（US スチールの母体）。以後、財産のほぼすべてを図書館・大学・平和事業に寄付しました。

### 経営マインド
- **「すべての卵を一つのかごに入れ、そのかごを見張れ」**: 分散投資の逆。集中して、徹底的に見張る。
- **コストへの執念**: 「利益は自然に出る。コストを見よ」。原価計算を製造業に持ち込んだ先駆者。
- **富の福音（1889年）**: 「金持ちのまま死ぬのは恥である」。富は社会からの預かり物という考え。

### 戦略の打ち手
- **垂直統合**: 鉄鉱石の鉱山、輸送する鉄道と船、コークス、製鉄所まで自社で持ち、コスト構造を支配。
- **不況期に投資**: 他社が止まる不況のときに最新設備を導入し、景気回復期に一気にシェアを取った。
- **優秀な人材にパートナーシップ（持分）を与える**: 「自分より優秀な人を使う術を知っていた男、ここに眠る」という墓碑銘を自ら望んだ。

### 失敗と教訓
- ホームステッド争議（1892年）で労働者と武力衝突し、多くの死傷者を出しました。コスト重視が労働者の敵意へ変わる典型例。**「人を大切にする」を怠ったときの代償は、財務では測れない**。

### あなたへの問い
- あなたの事業で、川上（仕入・供給）または川下（販売・顧客接点）を自社で持てば構造的に強くなる箇所はどこか。

## 2-2 ジョン・D・ロックフェラー ― 水平統合と「静かな独占」

### 背景
1839年生まれ。1870年にスタンダード・オイルを設立し、1880年代には米国の石油精製の約9割を支配。1911年に反トラスト法で解体されましたが、その分割会社（エクソン、モービル、シェブロンなど）が今も世界を代表する企業です。

### 経営マインド
- **秩序への信仰**: 乱立と過当競争は「無駄」であり、統合こそ効率だと本気で信じていた。
- **数字の人**: 若い頃から一セント単位で帳簿をつけ、生涯手放さなかった。
- **静かに、しかし徹底的に**: 派手さを嫌い、目立たずに競合を買収・吸収した。

### 戦略の打ち手
- **水平統合**: 同業の精製業者を次々に買収し、業界そのものを一社にまとめた。
- **輸送コストの支配**: 鉄道会社との大量輸送契約でリベート（割戻し）を得て、競合より安く運べる構造を作り、後にパイプラインを自ら敷設。**川上でも川下でもなく、「流通のボトルネック」を握った**。
- **規模の経済を価格に転嫁**: 灯油の価格を大幅に下げ、消費者にとっては恩恵となった。独占＝高価格ではなかった点が、単純な悪役像と異なるところ。

### 失敗と教訓
- 手法（秘密のリベート、圧力）が世論の怒りを買い、最終的に国家に解体されました。**戦略の正しさと、社会に受け入れられるかは別の問題**です。今日のプラットフォーム企業への規制も同じ構図です。

### あなたへの問い
- あなたの業界の「流通のボトルネック」（顧客との接点、仕入先、免許、データ）はどこにあり、誰が握っているか。

## 2-3 ヘンリー・フォード ― 大量生産と「日給5ドル」

### 背景
1863年生まれ。1903年にフォード・モーターを設立、1908年に T 型フォードを発売。1913年に移動式組立ライン（ベルトコンベア）を導入して生産時間を劇的に短縮し、1914年には労働者の日給を業界の約2倍の 5 ドルに引き上げました。

### 経営マインド
- **「顧客に何が欲しいか聞いていたら、"もっと速い馬"と答えただろう」**（伝承）: 顧客の声ではなく、顧客の課題を見る。
- **大衆のための製品**: 「私は大衆のための車を作る」。富裕層の玩具だった自動車を、労働者が買える値段にした。
- **賃金は費用ではなく需要**: 労働者が自社の車を買える給料を払えば、市場が広がる。

### 戦略の打ち手
- **単一モデル・単一色**: 「黒である限り、どんな色でも選べる」。品種を絞って規模を追求。
- **組立ラインによる時間短縮**: シャシー 1 台の組立時間を 12 時間強から約 1.5 時間へ。
- **日給5ドル**: 離職率の激減、生産性の向上、そして自動車を買う中間層の誕生。**人件費を上げて利益を上げた**。

### 失敗と教訓
- T 型への固執で、車種と色の多様化で攻めた GM にシェアを奪われました。**大成功した型を、自分で壊すのが最も難しい**（本田宗一郎の空冷と同じ構図）。

### あなたへの問い
- あなたの事業で「品種を絞って、圧倒的に速く安く」できる箇所はどこか。逆に、多様化で顧客を取り戻せる箇所はどこか。

## 2-4 ウォルト・ディズニー ― 物語を資産にする

### 背景
1901年生まれ。ミッキーマウス（1928年）、世界初の長編アニメーション『白雪姫』（1937年）、そしてディズニーランド（1955年）。破産と作品の権利喪失を経験しながら、キャラクターと物語を核にした事業モデルを発明しました。

### 経営マインド
- **「夢見ることができれば、それは実現できる」**: 楽観は才能ではなく選択。
- **品質への偏執**: 『白雪姫』は「ディズニーの愚行」と呼ばれる予算超過をしてでも完成度にこだわった。
- **キャラクターの権利を二度と手放さない**: 初期のキャラクター「オズワルド」を配給会社に奪われた経験から、自社で権利を持つことに徹底した。

### 戦略の打ち手
- **IP（知的財産）の多重利用**: 映画 → キャラクター商品 → テレビ → テーマパーク。一つの物語が複数の収益源になる「ディズニー・シナジー・マップ」（1957年の社内図が有名）。
- **ディズニーランド**: 映画スタジオが遊園地を作るという前例のない賭け。テレビ番組で資金と宣伝を同時に確保した。
- **体験の統制**: パーク内のキャスト（従業員）の言葉遣い、ゴミ箱の間隔まで「ショー」として設計。

### 現代への翻訳
- 西野亮廣（第5部）の「絵本 → 映画 → ミュージカル → 町」は、ディズニーの IP 多重利用の現代版です。**一つの世界観を、複数の接点で売る**。

### あなたへの問い
- あなたの事業の「物語」は何か。それは商品を離れても人に語られるものか。

## 2-5 レイ・クロック ― マクドナルド、フランチャイズと不動産

### 背景
1902年生まれ。ミルクセーキ用ミキサーのセールスマンだった52歳のとき、カリフォルニアのマクドナルド兄弟の店の効率に驚き、フランチャイズ権を獲得（1955年）。後に兄弟から権利を買い取り、世界最大の外食チェーンを作りました。

### 経営マインド
- **「やり遂げろ。この世で継続に勝るものはない」**: 遅咲きの人の言葉として重い。
- **QSC&V**: Quality（品質）、Service、Cleanliness（清潔）、Value。単純な基準の徹底。
- **フランチャイジーの成功が先**: 加盟店が儲からなければ本部も続かない。

### 戦略の打ち手
- **仕組みの標準化**: 調理手順、器具、店舗レイアウトを完全にマニュアル化し、誰がやっても同じ品質を出せるようにした。
- **不動産モデル（ハリー・ソネボーンの発案）**: 本部が土地を取得・賃借し、加盟店に転貸する。「マクドナルドはハンバーガー屋ではなく不動産業だ」と言われる収益構造。**表の商品と、裏の収益源を分けて設計する**。
- **ハンバーガー大学**: 教育機関を作り、文化と技術を伝達。

### 失敗と教訓
- マクドナルド兄弟との関係は決裂し、兄弟の店の近くに出店して潰したという逸話も残ります。**創業者の執念は、倫理と紙一重**。

### あなたへの問い
- あなたの事業を「誰がやっても同じ品質」にするために、マニュアル化すべき最初の 3 工程は何か。

## 2-6 サム・ウォルトン ― ウォルマート、「顧客がボス」と田舎からの逆張り

### 背景
1918年生まれ。1962年にアーカンソー州の小さな町にウォルマート 1 号店を開店。大手が見向きもしない地方の小都市に出店し続け、死去（1992年）の時点で米国最大の小売業に。現在も世界最大の売上を持つ企業の一つ。

### 経営マインド
- **「ボスは一人しかいない。顧客だ」**: 顧客は、他の店でお金を使うだけで社長から平社員まで全員をクビにできる。
- **倹約**: 億万長者になっても古いピックアップトラックに乗り続けた。**トップの倹約は、全社のコスト文化になる**。
- **現場を歩く**: 自家用機で店舗を回り、競合の店も見て回った。「良いアイデアはほとんど競合から学んだ」。

### 戦略の打ち手
- **田舎からの包囲**: 人口 5,000〜25,000 人の町（大手が「小さすぎる」と無視した市場）に出店。競合のいない場所で圧倒的な店になり、周辺の町を取りながら、最後に都市部へ。ランチェスター戦略の「局地戦」の教科書的事例。
- **EDLP（毎日低価格）**: 特売で客を呼ぶのではなく、常に安い。仕入と物流のコスト削減をそのまま価格に反映した。
- **物流センターとITへの先行投資**: 1980年代にサテライト通信網を持ち、店舗の販売データをリアルタイムに本部と取引先が共有。**小売業でありながら、実体はデータと物流の会社**。
- **従業員（アソシエイト）への利益分配**: 株式購入制度・利益分配で、店員をパートナーに変えた。

### 失敗と教訓
- 海外展開ではドイツと韓国から撤退。米国流をそのまま持ち込んだことが原因とされます。**国内で最強の型でも、海外では「型」ごと再設計が必要**。

### あなたへの問い
- あなたの業界で、大手が「小さすぎる」「面倒すぎる」と無視している顧客層はどこか。

## 2-7 イングヴァル・カンプラード ― IKEA、「顧客に働いてもらう」

### 背景
1926年スウェーデン生まれ。17歳で IKEA を創業（1943年）。1956年に「フラットパック（平たい箱に入れて顧客が組み立てる）」を導入し、世界最大の家具小売に。1976年の社内文書『ある家具商人の遺言』が IKEA の憲法です。

### 経営マインド
- **「より快適な毎日を、より多くの人々に」**: 低価格は目的ではなく、多くの人に届けるための手段。
- **コストへの執念**: 「無駄は死に至る病」。本人はエコノミークラスに乗り、社員にもホテルの節約を求めた。
- **単純さ**: 複雑な組織、肩書、会議を嫌った。

### 戦略の打ち手
- **フラットパック**: 輸送・保管・組立のコストを顧客に移し、そのぶん価格を下げた。**「顧客に働いてもらう」ことで、顧客も得をする**モデル。
- **価格から設計する**: 先に「売価いくら」を決め、それに合わせてデザイナーと工場が設計する。
- **店舗の動線設計**: 一方通行の迷路のような店内、レストラン、ショールーム。滞在時間を伸ばし、衝動買いを生む。
- **カタログとブランドの世界観**: 商品ではなく「暮らし」を見せた。

### 失敗と教訓
- 若い頃の政治的な過ちが後年に発覚し、公に謝罪しました。**創業者の過去は、いつか必ず表に出る前提で行動する**。

### あなたへの問い
- あなたの事業で、顧客に一部の工程を任せることで「顧客も得をし、コストも下がる」箇所はどこか。

## 2-8 ハーブ・ケレハー ― サウスウエスト航空、「従業員第一」で高収益

### 背景
1931年生まれ。1967年に設立されたサウスウエスト航空の共同創業者・長年の CEO。大手が敵対する中で低価格の短距離路線に特化し、米国航空業界で最も長く連続黒字を続けた会社（40年以上）を作りました。

### 経営マインド
- **従業員第一、顧客第二、株主第三**: 従業員が幸せなら顧客に良いサービスをし、顧客が満足すれば株主が報われる。順番が重要。
- **「態度で採用し、スキルは教える」**: ユーモアと協調性を採用基準にした。
- **単純さの力**: 複雑な戦略ではなく、単純なことを誰よりも徹底する。

### 戦略の打ち手
- **単一機種（ボーイング737）**: 整備・訓練・部品を統一し、コストと折り返し時間を劇的に削減。
- **ポイント・トゥ・ポイント**: ハブ空港を経由せず、都市間を直行。地方の第二空港を使う。

### 現代への翻訳
- マイケル・ポーターが「戦略とは何をやらないかを決めることだ」と説明するときに必ず使う事例です。**単純な型を、業界の誰よりも徹底する**ことが最強の差別化になります。

## 3-10 出雲充 ― ユーグレナ、「500社に断られた」からの上場

1980年生まれ。大学時代にバングラデシュで栄養問題を見て、ミドリムシ（ユーグレナ）に可能性を見出す。2005年にユーグレナ社を設立、同年に世界初の屋外大量培養に成功。しかし販売先・出資者が見つからず、約 500 社に断られたのち伊藤忠が出資（2008年）。2012年に東証マザーズ上場、その後バイオ燃料へ挑戦。

### 経営マインド
- **「1社が OK と言うまで、断られ続けるだけ」**: 断られた 499 社は失敗ではなく、1 社を見つけるための過程。
- **社会課題から始める**: 技術は手段。「バングラデシュの子どもの栄養失調をなくす」という目的が先。

### 戦略の打ち手
- **最初の大企業パートナーを勝ち取る**: 1 社の信用が、残りの数百社の扉を開いた。**新市場では「最初の一社」を取ることにすべてを賭ける**。
- **食品（キャッシュ）でエネルギー（夢）を育てる**: 健康食品で収益を作り、バイオジェット燃料の研究に投資。

### あなたへの問い
- あなたの事業で「これが取れれば残りが動く」最初の 1 社（1 人）は誰か。

## 3-11 堀江貴文 ― ライブドア、速度と、コンプライアンスの教訓

### 背景
1972年生まれ。1996年、東京大学在学中にオン・ザ・エッヂを創業、2000年に上場。ライブドアとして買収を重ね、2004年のプロ野球参入表明、2005年のニッポン放送株取得で社会現象に。2006年に証券取引法違反で逮捕、上場廃止。出所後は、宇宙ロケット（インターステラテクノロジズ）、飲食、メディア、著書（『多動力』ほか）で活動。

### 学ぶべき点
- **速度と実行力**: 「やりたいことは、まずやる」。情報発信と行動の速さは現在の起業家文化に大きく影響を与えました。
- **既得権益への挑戦**: 放送・野球という閉じた業界に正面から挑み、業界の問題を世に問うた。

### 教訓（重い）
- **上場企業のルールは「守れば良い」ではなく「守っていると見える」ところまで求められる**。会計処理の判断一つで会社は消えます。攻める経営者ほど、守り（法務・会計・ガバナンス）を自分より厳しい人間に任せる必要があります。
- 敵を作りすぎる戦い方は、いざというとき味方がいません。**業界を変えるときは、業界の中に味方を作る**（小倉昌男が世論を味方につけたのと対照的）。

### あなたへの問い
- あなたの会社に、あなたに「ダメです」と言える人（監査役・顧問・番頭）はいるか。

## 4-1 スティーブ・ジョブズ ― 集中、美意識、「点と点をつなぐ」

### 背景
1955年生まれ。1976年に Apple を共同創業、1985年に自ら招いた CEO によって追放される。NeXT と Pixar を経て 1997年に Apple へ復帰。iMac（1998年）、iPod（2001年）、iPhone（2007年）、iPad（2010年）で、倒産寸前の会社を世界で最も価値のある企業にしました。2011年没。

### 経営マインド
- **フォーカス＝「ノー」と言うこと**: 復帰直後、数十の製品ラインを 4 象限（コンシューマー/プロ × デスクトップ/ノート）に絞った。「私たちがやらないと決めたことを、私はやったことと同じくらい誇りに思う」。
- **顧客は自分の欲しいものを知らない（見せるまでは）**: 「フォーカスグループで製品をデザインするのは難しい」。盛田昭夫と同じ。
- **点と点をつなぐ（Connecting the dots）**: カリグラフィの授業が Mac の美しいフォントになった。将来を見て点をつなぐことはできない、振り返ってつなぐことしかできない。だから今の直感を信じるしかない。
- **A プレイヤーは A プレイヤーを雇う。B は C を雇う**: 妥協した採用は組織を腐らせる。
- **ハングリーであれ、愚かであれ（Stay hungry, stay foolish）**。

### 戦略の打ち手
- **ハードとソフトとサービスの垂直統合**: 体験全体を支配する。「1000曲をポケットに」は iPod + iTunes + 音楽レーベル交渉のセットで成立した。
- **少数の製品に全力**: 巨大企業になっても製品数はテーブルに載る程度。
- **発表（プレゼン）そのものを製品にする**: 「One more thing」。ストーリーで市場を創る。
- **サプライチェーンをティム・クックに任せる**: 自分は製品と発表に集中し、オペレーションは最高の人に委ねた。本田と藤沢の関係に近い。

### 失敗と教訓
- 1985年の追放。若い頃の傲慢さと、組織を動かす力の欠如が原因でした。追放後の 12 年で「人を率いる」ことを学んだと本人は語っています。**天才性は、組織力なしでは会社を壊す**。

### あなたへの問い
- いま抱えている商品・サービス・施策を全部並べて、半分を止めるとしたら何を残すか。

## 4-2 ジェフ・ベゾス ― Day 1、顧客起点、フライホイール

### 背景
1964年生まれ。ヘッジファンドの幹部職を辞めて 1994年に Amazon を創業（オンライン書店）。1997年上場。その後「エブリシング・ストア」、Prime（2005年）、AWS（2006年）、Kindle、Alexa。2021年に CEO を退任。

### 経営マインド
- **Day 1**: 「Day 2 は停滞、そして衰退、そして死だ。だから常に Day 1 であれ」。1997年の株主への手紙を毎年の年次報告に添付し続けた。
- **顧客への執着（Customer Obsession）**: 競合ではなく顧客を見る。「顧客は常に不満を持っている。それが発明の源泉」。
- **後悔最小化フレームワーク**: 80 歳になった自分が、挑戦しなかったことを後悔するか？で創業を決めた。
- **長期思考**: 「短期の利益より長期のキャッシュフロー」。四半期の株価に反応しない。
- **誤解される覚悟**: 「長期間、誤解される覚悟がなければ発明はできない」。

### 戦略の打ち手
- **フライホイール（弾み車）**: 低価格 → 顧客増 → 出品者増 → 品揃え増 → 顧客体験向上 → さらに顧客増、そして規模でコストが下がりまた低価格へ。**自己強化するループを描き、どの一点を押せば全体が回るかを見極める**。
- **Working Backwards**: 新製品はまず「発売時のプレスリリースと FAQ」を書き、顧客にとっての価値が明確なものだけ作る。
- **6 ページのメモ、パワポ禁止**: 会議の冒頭で全員が黙って読む。思考の質を文章で担保する。
- **Two-pizza team**: ピザ 2 枚で足りる人数のチームに分けて、自律的に動かす。
- **AWS**: 社内インフラを外販し、本業と関係ない最大の利益源を作った。**自社のために作った仕組みは、外にも売れる**。
- **「あなたの利益率は、私の機会だ」**: 高マージンの業界は、低価格で参入する余地がある。

### 失敗と教訓
- Fire Phone は大失敗。ベゾスは「大きく賭けるなら、大きな失敗も何度かある。それが投資の分散だ」と言い切った。**失敗を「実験のコスト」として最初から予算化する**。

### あなたへの問い
- あなたの事業のフライホイールを 1 枚の図に描け。どの一点を押せば全体が回り始めるか。

## 4-3 イーロン・マスク ― 第一原理思考と「不可能を工程表にする」

### 背景
1971年南アフリカ生まれ。Zip2、X.com（後の PayPal）を売却した資金で、2002年に SpaceX、2004年に Tesla へ投資して参画（後に CEO）。SolarCity、Neuralink、The Boring Company、2022年に Twitter（現 X）買収、xAI。再使用ロケットと EV の大衆化という、専門家が「無理」と言った 2 つを実現しました。

### 経営マインド
- **第一原理思考（First Principles）**: 類推（「業界ではこうだ」）ではなく、物理法則と原材料費まで分解して「本来いくらでできるか」から考える。ロケットの原材料費は販売価格の数%しかなかった → 自分で作れば安くできる。
- **ミッションが先**: 「人類を多惑星種にする」「持続可能なエネルギーへの移行を加速する」。人材と資金はミッションに集まる。
- **失敗は選択肢に含まれている**: 「失敗していないなら、十分に革新していない」。ロケットは爆発しながら改善する。
- **極端な当事者意識**: 工場に寝泊まりし、生産ラインの問題を自ら解決する（「生産地獄」）。

### 戦略の打ち手（マスクの「アルゴリズム」5 段階）
1. **要件を疑え**: すべての要件には、それを決めた人の名前をつけろ。「部署」が決めた要件は疑え。
2. **部品や工程を削れ**: 後で 10% 戻す羽目にならないなら、削り方が足りない。
3. **単純化・最適化せよ**: 削った後にやること。存在すべきでないものを最適化するな。
4. **サイクルタイムを短縮せよ**。
5. **自動化せよ**: これは最後。順番を逆にすると失敗する。

- **垂直統合**: 電池からソフトウェア、販売（ディーラーを持たない直販）まで。
- **製品を先に見せて予約金を集める**: Model 3 は発表 1 週間で数十万台の予約。**顧客の資金で生産を立ち上げる**。
- **本人が広告塔**: 広告費ゼロ、X（Twitter）での発信が最大のマーケティング。

### 失敗と教訓
- 発言による法的トラブル（Tesla 非公開化ツイート）、Twitter 買収後の混乱、過酷な労働環境への批判。**個人の発信力は、会社の最大の資産にも最大のリスクにもなる**。

### あなたへの問い
- あなたの商品の「原材料費・本来必要な工数」だけを積み上げると、いくらになるか。今の価格との差はどこで消えているか。

## 4-4 ビル・ゲイツ ― プラットフォームと「すべての机に PC を」

### 背景
1955年生まれ。1975年にハーバードを中退して Microsoft を共同創業。1980年の IBM との MS-DOS 契約で、**IBM に独占権を渡さず、他社にもライセンスできる権利を残した**。Windows（1985年）、Office で PC 時代の標準を握り、2008年に経営から退いて財団活動へ。

### 経営マインド
- **「すべての机、すべての家庭にコンピュータを」**: 創業時のビジョン。
- **偏執的な危機感**: 「Microsoft は常に倒産まで 2 年」。
- **考える週（Think Week）**: 年に 2 回、山小屋にこもって論文と社内提案を読む。
- **学び続ける**: 年間 50 冊の読書。

### 戦略の打ち手
- **ハードではなくソフト（OS）を押さえる**: PC メーカーが乱立しても、全員が Microsoft の OS を必要とする構造。
- **非独占ライセンス**: IBM との契約の一条項が、数十年の支配を決めた。**契約書の一行が戦略そのもの**。
- **アプリケーションとの垂直統合（Office）** と、開発者エコシステム（「デベロッパー、デベロッパー、デベロッパー」）。
- **インターネットへの急旋回（1995年「インターネットの潮流」メモ）**: 出遅れを認めて全社を転換した。

### 失敗と教訓
- 反トラスト訴訟（1998年〜）、スマートフォン OS での敗北。**独占的地位は、次の波を見る目を曇らせる**。

### あなたへの問い
- あなたの業界で、参加者全員が必要とする「OS」（共通の標準・道具・データ）にあたるものは何か。

## 4-5 ジェンスン・フアン ― NVIDIA、「30 日で潰れる会社」と 10 年の賭け

### 背景
1963年台湾生まれ。1993年に NVIDIA を共同創業。ゲーム用 GPU で生き残り、2006年に GPU を汎用計算に使う CUDA を発表。長年「無駄な投資」と言われ続けたが、2012年以降の深層学習ブーム、そして 2022年以降の生成 AI で、世界で最も価値のある企業の一つになりました。

### 経営マインド
- **「我が社はいつも倒産まで 30 日」**: 時価総額が数兆ドルになっても、社内では同じ言葉を使い続けている。
- **「10 億ドル市場ではなく、0 ドル市場（ゼロ・ビリオン・ダラー・マーケット）を狙え」**: まだ存在しない市場を作る。存在する市場は既に強者がいる。
- **苦しみを歓迎する**: 「偉大さは知性ではなく、性格から生まれる。性格は苦しみからしか生まれない」。
- **フラットで直接**: 数十人の直属の部下、階層を嫌う、1on1 をせず全員の前で議論する。

### 戦略の打ち手
- **CUDA への 10 年以上の先行投資**: 使い道が見えない時期に、開発者向けのソフトウェア基盤に投資し続けた。AI の波が来たとき、競合はハードは作れてもソフトのエコシステムが無かった。**「堀」はハードではなくソフトと開発者コミュニティ**。
- **プラットフォーム企業への転換**: チップ売りから、AI のフルスタック（チップ・ネットワーク・ソフト・クラウド連携）へ。
- **速度**: 「光の速さで動く」。製品サイクルを年 1 回に短縮。

### あなたへの問い
- あなたの業界で「まだ売上ゼロだが、10 年後に必ず来る」領域はどこか。そこに今、投資しているか。

## 4-6 リード・ヘイスティングス ― Netflix、「ルールなし」の文化と自己破壊

### 背景
1960年生まれ。1997年に DVD 郵送レンタルの Netflix を創業。ブロックバスター（当時の巨人）に買収を提案して断られ、2007年にストリーミングへ転換。2013年からオリジナル作品（『ハウス・オブ・カード』）、世界 190 か国以上へ。著書『NO RULES』（2020年）。

### 経営マインド
- **「能力密度」を上げる**: 平凡な人材を減らし、優秀な人材の密度を高めれば、ルールが要らなくなる。
- **率直さ（Radical Candor）**: 上司にも率直にフィードバックする文化。
- **「私たちはチームであって、家族ではない」**: プロスポーツチームのように、ポジションに最適な人を置く。
- **コンテキストで導き、コントロールしない**: 判断に必要な情報を与え、ルールで縛らない。

### 戦略の打ち手
- **自社事業の共食い（カニバリゼーション）を自ら選ぶ**: DVD 事業が絶好調のときにストリーミングへ移行。**次の波は、自分で自分を壊した者だけが乗れる**。
- **データで作品を決める**: 視聴データにもとづき、オリジナル作品に巨額投資。
- **グローバル同時展開**: 2016年に一気に 130 か国へ。ローカルの制作（『イカゲーム』など）が世界で当たる構造を作った。

### 失敗と教訓
- 2011年の「Qwikster」（DVD 事業の分社と値上げ）は顧客の猛反発で撤回、株価は 8 割下落。**戦略が正しくても、顧客への説明の順序を間違えると死にかける**。

### あなたへの問い
- あなたのいまの主力事業を、3 年以内に食ってしまう可能性のある技術・モデルは何か。それを自分で先にやるか。

## 4-7 ブライアン・チェスキー ― Airbnb、「スケールしないことをやる」と「11 つ星の体験」

### 背景
1981年生まれ。デザイナー出身。2008年、家賃が払えずに自室のエアマットレスを貸したのが Airbnb の始まり。Y Combinator に参加し、資金難のときはシリアルの箱（オバマ・オーズ）を売って凌いだ。2020年、コロナで売上が 8 割消えた直後に IPO。

### 経営マインド
- **「スケールしないことをやれ」**（ポール・グレアムの助言）: 初期はニューヨークのホストの家を一軒ずつ訪ね、写真を自分たちで撮り直した。**最初の 100 人のユーザーを、手作業で熱狂させる**。
- **11 つ星の体験**: 5 つ星は「期待通り」。6 つ星、7 つ星…と極端に想像することで、実現可能な「6 つ星」の要素が見える。
- **デザイン思考**: 体験をストーリーボード（絵コンテ）で描いてから作る。
- **ファウンダー・モード（2024年）**: 大企業になっても、創業者は「マネージャー・モード」（任せきり）ではなく、細部に入り込む「ファウンダー・モード」を保つべき、という論争を起こした。

### 戦略の打ち手
- **信頼の設計**: 見知らぬ人の家に泊まる不安を、レビュー・本人確認・保険・決済のエスクローで解消。**マーケットプレイスの本質は「信頼の製造」**。
- **危機での集中**: 2020年に事業を宿泊の核だけに絞り、コスト構造を再設計してから上場。
- **ブランドとコミュニティ**: ホストを「パートナー」として遇し、コミュニティの声を製品に反映。

### あなたへの問い
- あなたのサービスの「11 つ星」はどんな体験か。そこから逆算して、明日実装できる「6 つ星」は何か。

## 4-8 ピーター・ティールとポール・グレアム ― スタートアップの「思想」

### ピーター・ティール（1967年生、PayPal 共同創業者、Palantir、Founders Fund。著書『ゼロ・トゥ・ワン』2014年）
- **競争は敗者のためのもの**: 同じ市場で競争すると利益は消える。**独占（誰にも真似できない価値）を目指せ**。
- **0 → 1 と 1 → n**: 既にあるものを増やす（1→n）ではなく、無かったものを作る（0→1）。
- **小さな市場を独占してから広げる**: PayPal は eBay のパワーセラーから、Facebook はハーバードから。
- **10 倍良いものを作れ**: 2 倍では乗り換えてもらえない。
- **秘密（Secret）を持て**: 「重要な真実で、ほとんどの人が同意しないものは何か？」
- **スタートアップが答えるべき 7 つの質問**: 技術、タイミング、独占、人材、販売、永続性、秘密。

### ポール・グレアム（1964年生、Viaweb を Yahoo に売却、2005年に Y Combinator を共同設立。Airbnb、Dropbox、Stripe、Reddit などを輩出）
- **「人が欲しがるものを作れ（Make something people want）」**: YC の標語。
- **「スケールしないことをやれ」**: 初期は手作業で顧客を獲得し、熱狂を作れ。
- **「ラーメン代を稼げる状態（Ramen profitable）」**: 創業者の生活費を賄える売上を早く作ると、選択肢が広がる。
- **「デフォルトで生きているか、死んでいるか」**: 現在の成長率と資金で、資金が尽きる前に黒字化できるか。
- **成長率がスタートアップの定義**: 週 5〜7% の成長を目標に。
- **ファウンダー・モード（2024年）**: チェスキーの講演を受けて、「創業者は"任せろ"という通説を疑え」と説いた。

### 現代への翻訳
- 二人の思想は「小さく始めて、狭い市場を独占し、10 倍良いものを作り、手作業で熱狂を作る」に集約されます。西野亮廣のオンラインサロン、中野優作の YouTube 集客は、まさにこの順序で動いています。

### あなたへの問い
- あなたが持っている「重要な真実で、業界のほとんどの人が同意しないもの」は何か。

## 4-9 ジャック・マー（馬雲）― アリババ、「顧客第一・従業員第二・株主第三」

### 背景
1964年生まれ。英語教師から 1999年にアリババを創業。中小企業向け BtoB から、eBay に対抗する個人向けの「タオバオ」（2003年、出店無料で eBay 中国を撤退させた）、決済の「アリペイ」へ。2014年にニューヨーク証券取引所へ上場（当時史上最大の IPO）。2019年に会長を退任。

### 経営マインド
- **顧客第一、従業員第二、株主第三**: ケレハーと同じ順序。
- **「今日は厳しい、明日はもっと厳しい、明後日は素晴らしい。でも多くの人は明日の夜に諦める」**。
- **小さい者の味方**: 「私たちは中小企業を助けるために存在する」。
- **弱点を強みに**: 「私は技術が分からない。だから技術者の言うことを顧客の目で判断できる」。

### 戦略の打ち手
- **無料で市場を取る**: タオバオの出店無料で eBay の課金モデルを崩し、広告と決済で収益化。
- **信頼インフラの構築**: アリペイのエスクロー決済で、見知らぬ者同士の取引を可能にした（Airbnb と同じ「信頼の製造」）。
- **「ダブルイレブン（独身の日）」**: 2009年に始めた 11 月 11 日のセールを、世界最大の商戦日に育てた。**イベントを発明して需要を作る**。
- **ミッションと価値観の徹底**: 「六脈神剣」と呼ばれる価値観を評価に組み込んだ。

### 失敗と教訓
- 2020年の当局批判の講演後、アント・グループの IPO が直前で中止。**政治・規制のリスクは、成功が大きいほど大きい**（岩崎弥太郎の項と同じ構図）。

### あなたへの問い
- あなたの事業で「無料にして市場を取り、別のところで収益化する」設計は成立するか。

## 4-10 ハワード・シュルツ ― スターバックス、「第三の場所」と危機の再建

### 背景
1953年生まれ。1982年にシアトルのコーヒー豆販売店スターバックスに入社、イタリアのエスプレッソバー文化に衝撃を受け、独立してカフェを開業した後、1987年にスターバックスを買収。世界数万店に。2008年、業績悪化で CEO に復帰し、全米の店舗を半日閉めてバリスタ再教育を実施した逸話は有名です。

### 経営マインド

- **直営主義**: フランチャイズに頼らず、品質と文化を直営で守った（空港などは例外）。
- **危機時の「原点回帰」**: 店舗閉鎖・不採算店の整理・バリスタ教育・エスプレッソマシンの変更。**再建は「ブランドの約束」を思い出すところから**。

## 4-12 アマンシオ・オルテガ ― ZARA、速さそのものを武器にする

## 4-13 イヴォン・シュイナード ― パタゴニア、「地球が唯一の株主」

- **所有構造そのものを戦略にする（2022年）**: 上場も売却もせず、利益を環境保護に流す構造にした。**「上場しない」という選択肢を最も鮮やかに示した企業**。

### あなたへの問い
- あなたの会社が「売上を減らしてでも守りたいもの」は何か。それがブランドの核になる。

## 4-14 レイ・ダリオ ― ブリッジウォーター、「徹底した透明性」と原則

# 第5部 キングコング西野亮廣 ― 信用経済と「応援シロ」の設計者

## 5-1 なぜ「芸人」を経営者として学ぶのか

西野亮廣（1980年生まれ）は、お笑いコンビ「キングコング」として 1999年にデビューし、テレビで人気を得たあと、2010年代に絵本作家、そして「エンタメの実業家」へ活動の重心を移した人物です。絵本『えんとつ町のプペル』（2016年）は数十万部のヒットとなり、映画（2020年）、歌舞伎、ミュージカル、そしてニューヨークでの英語ミュージカル化へと広がりました。国内最大級のオンラインサロン「西野亮廣エンタメ研究所」を運営し、2021年に吉本興業から独立、株式会社 CHIMNEY TOWN を率いています。

彼を本書に入れる理由は 3 つあります。

1. **「信用」を資本にする現代のビジネスモデルを、誰よりも早く、言葉と実践の両方で示した**（『革命のファンファーレ』2017年、『新世界』2018年、『夢と金』2023年）。
2. **個人（クリエイター）が、会社を持たない状態からコミュニティで資金と労働力を調達し、上場企業並みの事業規模のプロジェクト（映画、ミュージカル）を動かした**。
3. **炎上と批判を「織り込み済み」で行動する、現代特有のリスク管理を体現している**。

## 5-2 転機：「テレビの世界の勝ち方」を捨てた日

若くして冠番組（『はねるのトびら』）を持ちながら、西野はテレビの世界での成功に危機感を持ちました。理由は、**テレビの視聴者は年々減り、しかも「テレビに出ている人が偉い」という構造は他人（局・スポンサー）が決めている**からです。

- 2000年代後半から絵本制作を開始。当初は 1 人で数年かけて描いていた。
- ハロウィン翌日の渋谷のゴミ拾いを続け、ゴミから「ゴミ人間」＝プペルの着想を得た。
- **「自分がいちばんになれる土俵を自分で作る」**という発想で、「芸人が絵本を描く」という誰もいない市場を選んだ。ティールの「小さな市場を独占する」と同じ。

## 5-3 経営マインド：西野の思考の核

### (1) お金ではなく「信用」を稼ぐ
『革命のファンファーレ』の中心概念です。**クラウドファンディングは「信用をお金に換金する装置」**であり、信用のない人がクラファンをやっても集まらない。逆に、信用を貯めた人はいつでも資金を調達できる。

信用を貯める方法は単純で、**嘘をつかないこと**。しかしテレビタレントは「本当はまずいものを『美味しい』と言う」仕事をさせられるため、構造的に信用を失う。だから西野は、嘘をつかなくて済む環境（自分でプロジェクトを持つ）に身を置くことを選んだ。

> 経営者への翻訳: **信用残高が事業の資本金である。** 発信の際に「一度でも嘘をつくと、信用残高がゼロになる」と考える。

### (2) 「無料公開」は損ではなく、入口の設計
2017年、『えんとつ町のプペル』の全ページをネットで無料公開しました。「クリエイターの敵だ」と炎上しましたが、結果として売上は増えました。西野の説明はこうです。

- 人は「内容を知らないもの」にはお金を払わない。**「知っているもの」の「確認作業」にお金を払う**（旅行先で知っている観光地に行くように）。
- 絵本は「読み聞かせる親が、まず内容を知ってから買う」商品。だから中身を見せるほど売れる。
- 無料公開はフリーミアム。**入口を無料にして、出口（本・グッズ・体験）で回収する**。

> 経営者への翻訳: **あなたの商品で「知られていないから買われていない」部分はどこか。** そこは無料にしても損をしない。

### (3) 「認知」と「人気」は違う
テレビに出れば認知は取れる。しかし認知は行動につながらない。**人気（この人を応援したい）だけが、お金と時間を動かす。** 認知は広告で買えるが、人気は買えない。人気は、時間をかけた一貫した行動からしか生まれない。

### (4) 「作品」ではなく「応援シロ」を売る
完成した作品を売るのは難しい。しかし、**作る過程を見せ、「あと少しで完成する」「一緒に作れる」という余白（応援シロ）を残すと、人は参加したくなる**。オンラインサロンで制作過程を毎日公開し、クラファンで参加させ、公開日には「自分が作った作品」として観に来てもらう。

> 経営者への翻訳: **顧客を「消費者」から「共犯者」にする。** 開発途中を見せる、命名に参加させる、初期顧客に特別な役割を与える。

### (5) セカンドクリエイター（作り手を増やす）
絵本の分業制（背景・キャラクター・彩色を別のクリエイターに発注し、西野は総合監督）、映画では数百人。さらに「読み聞かせ会」「個展」をファンが自主開催できるように、権利を緩く開放した。**作り手が増えれば、売り手も増える。**

### (6) お金の話をタブーにしない（『夢と金』）
「夢を語る人ほどお金の話を避けるが、夢を続けるにはお金が要る」。特に、以下の 3 点。

- **プレミアムとラグジュアリーの違い**: プレミアムは「競合の中で高い（機能差で正当化）」。ラグジュアリーは「競合がいない（夢・物語・希少性を売る）」。日本企業は前者ばかりで、後者が苦手。
- **富裕層向けの席を用意せよ**: 「全員に安く」ではなく、**支払いたい人が高く払える選択肢**（VIP 席、限定版、名前を刻む権利）を作ることで、その利益で一般価格を下げられる。
- **「機能検索」から「人検索」へ**: 機能で選ばれる商品は AI と価格競争で消える。「あの人から買いたい」だけが残る。

### (7) ファーストペンギンでいる
最初に飛び込む者は叩かれるが、その領域の第一人者になれる。西野はクラファン、オンラインサロン、無料公開、NFT/DAO、海外ミュージカル化のすべてで「日本のエンタメ界で最初にやる人」であり続けた。**批判は、先行者利益の対価**として計上している。

## 5-4 戦略の打ち手：IP を「町」にする

西野の戦略を一本の線で見ると、ディズニーの IP 多重利用を、個人が SNS 時代に再現したものです。

| 段階 | 打ち手 | 資金・労働力の源泉 |
|------|--------|-------------------|
| 1 | 絵本（2016年） | クラファンで制作費と初期購入者を確保 |
| 2 | 無料公開・個展・読み聞かせ会 | ファンが自主開催（権利の開放） |
| 3 | オンラインサロン | 月額会費で安定収入 + 数万人の「参加者」 |
| 4 | 映画（2020年） | 4 年半の制作、サロンで過程を公開、公開後も舞台挨拶を大量に実施 |
| 5 | 歌舞伎・ミュージカル（国内） | IP の再解釈で新しい客層へ |
| 6 | 英語ミュージカル『Chimney Town the Musical』（ニューヨーク） | ブロードウェイ級の作曲家を起用し、国際市場向けに脚本・名前（プペル→Binny）を再設計 |
| 7 | 町（地元・兵庫県川西市など）、美術館構想、DAO | 物理空間とコミュニティの融合 |

ポイントは 3 つです。

1. **資金調達を「銀行・VC」に頼らず、ファンから直接行った**。上場企業とは逆のルートで「多くの人の資本で事業を行う」渋沢の合本主義を実現している。
2. **各段階の顧客が次の段階の宣伝者になる**。ベゾスのフライホイールと同じ構造。
3. **海外進出では「そのまま持っていかない」**。名前も脚本も変え、現地の一流と組む。ソニーの盛田がニューヨークに住んだのと同じく、「現地の文法」に合わせている。

## 5-5 集客の型：西野流を分解する

西野の集客は「広告を出す」のではなく、**毎日の発信で信用を積み、コミュニティに閉じ込め、そこから外に波及させる**型です。

1. **毎日、長文を書く**（サロン記事、Voicy、ブログ）。量と継続で信用を作る。
2. **裏側を全部見せる**（収支、失敗、悩み）。透明性が信用になる。
3. **入口は無料か安価**（無料公開、YouTube、書籍）。
4. **中間層は月額コミュニティ**（サロン）。ここが安定収益と労働力の源。
5. **上位層に高額商品**（VIP 席、権利、名前を刻む）。
6. **イベントで一気に外に出す**（映画公開、クラファン、ミュージカル）。

これは第 8 部で「4 層の集客モデル」として一般化します。

## 5-6 批判と限界

- **「信者ビジネス」「宗教的」という批判**: コミュニティが強くなるほど、外部からは閉鎖的に見える。西野自身は「批判は無料の宣伝」と割り切っていますが、**採用・提携・上場のような「外部の信用」が必要な局面では、コミュニティの熱量だけでは足りない**。
- **属人性**: 西野本人が発信を止めれば、事業のエンジンも止まる。上場を目指す企業は、この属人性を「仕組み」に置き換える必要があります（第 8 部）。
- **海外挑戦はまだ途上**: ニューヨークでのミュージカルは多額の資金と長い年月がかかる、結果が出るまで評価は保留です。ただ、「日本で当たったものを、名前を変えてでも現地に合わせる」姿勢は、海外挑戦の教科書になります。

## 5-7 あなたへの問い
- あなたの事業で、「完成品」ではなく「作る過程」を売れる部分はどこか。
- あなたの顧客は「認知している人」か「応援している人」か。後者は何人いるか、数えられるか。
- 富裕層・熱狂層が「もっと払いたい」と言ったとき、受け皿（高額商品）はあるか。

# 第6部 バディカ 中野優作 ― 業界の常識を「誠実」で壊す

## 6-1 経歴：業界の「内側」を知り尽くした人が、外に出て変える

中野優作（1982年生まれ、香川県出身）の経歴は、本書の中でも異色です。

- 高校を 2 か月で中退し、土木作業員などを経て、2008年に中古車販売大手のビッグモーターに入社。
- 営業未経験から店舗トップの売上を記録し、約 1 年半、28 歳で店長に。その後、本部の幹部、子会社（ハナテン）の社長を務める。
- 2017年に退社し、同年 6 月、香川県高松市で株式会社 BUDDICA（バディカ）を創業。当初は業者間売買（BtoB）が中心。
- 業者向け販売サイト（オートサーバー）で 2021年度に全国 1 位の販売台数を記録。
- 2023年、古巣ビッグモーターの保険金不正請求問題が社会問題化。元幹部として YouTube 等で業界構造を解説し、一気に知られる存在に。同年 8 月に著書『クラクションを鳴らせ！ 変わらない中古車業界への提言』（幻冬舎）を刊行。
- 2024年 2 月、中古車をオンラインで完結して買える BUDDICA DIRECT（バディカダイレクト）を創業。本格稼働から 8 か月で累計売買 1,000 台を突破。
- 創業から約 7 年で年商 100 億円規模に到達し、従業員の「やりがい」に関するランキングで日本一と評価される組織を作った、と本人が講演で語っています。

**「業界の内側で頂点を見た人が、その業界の問題を知り尽くしたうえで、顧客側に立って作り直す」**。これは小倉昌男（宅急便）や、稲盛和夫（第二電電）と同じ「業界変革者」の型です。

## 6-2 転機：「本当に申し訳ないことをした」から始まる

中野の発信の特徴は、**過去の自分と業界の問題を、隠さず、言い訳せずに認めるところから始めた**点です。幻冬舎の記事タイトルにもあるように、「懺悔」からの出発でした。

これは、単なる誠実さのアピールではなく、戦略的にも重要です。

- 業界批判をする人は多いが、**内側にいた当事者の告白は、比較にならない信用を生む**。
- 自分の非を先に認めることで、「あなたも同じ穴のムジナだ」という反論を封じた。
- 「変わらない業界への提言」という形で、批判ではなく**代替案（バディカ）とセット**で語った。

> 経営者への翻訳: **業界を変えるなら、まず自分の過去の加担を認める。** それが最も強い「信用の初期投資」になる。

## 6-3 経営マインド：中野の思考の核

### (1) 「営業はもっとも尊い仕事」であり、だからこそ「売らせる仕組み」を壊す
中野は営業出身であり、営業を否定しません。しかし、**営業マンが顧客を騙してしまうのは、個人の資質ではなく「そうしないと生きていけない評価・報酬制度」のせい**だと見抜きました。

- 高い個人ノルマと、売上に連動する強いインセンティブは、短期的には数字を作るが、顧客を「カモ」に変える。
- バディカでは、営業が「顧客にとって最適でない車を売らなくてよい」構造を作ることを重視し、ノルマや売上連動の報酬に依存しないマネジメントを公言しています。
- **顧客が満足し、紹介・再購入につながることが、長期では最も利益になる**という信念。

> 経営者への翻訳: **社員の行動は、あなたが設計した評価制度の「出力」である。** 顧客を裏切る社員が出たら、まず制度を疑う。

### (2) 透明性：「隠すから儲かる」業界で、全部見せる
中古車業界は、車両の状態・修復歴・仕入値・整備内容・保証の中身など、**情報の非対称性が利益の源泉**になってきた業界です。中野はその逆を行きました。

- 価格、車両状態、整備内容、手数料をできる限り開示する。
- 業界の「裏側」（なぜ諸費用が高いのか、なぜ下取りが安いのか）を YouTube で解説する。
- 顧客が知識を持てば持つほど、誠実な店が選ばれる。**業界全体の透明性を上げることが、自社の最大の差別化になる**。

### (3) 従業員の「やりがい」を経営指標にする
「7 年で年商 100 億円」と並べて「やりがいランキング日本一」を語る点が、中野の特徴です。ケレハー（従業員第一）、ジャック・マーの順序と同じで、**顧客への誠実さは、従業員が尊重されている組織からしか生まれない**という考えです。

- 元ビッグモーターの社員も含め、「業界で傷ついた人」を受け入れて再教育する。
- 社長自身が失敗・危機を社員とファンの前で語る（創業メンバーとの 9 年間の軌跡を語る動画など）。

### (4) 地方（香川）から全国、そしてオンラインへ
本社は高松市。中古車の販売は「商圏」が命でしたが、中野は **YouTube で全国に信用を作り、LINE とオンラインで購入を完結させる**ことで、地方の会社が全国の顧客を持てる構造を作りました。ウォルマートの「田舎からの包囲」の、デジタル版です。

## 6-4 戦略の打ち手

| 打ち手 | 内容 | 学ぶべき点 |
|--------|------|-----------|
| **BtoB からの出発** | 創業時は業者間売買で資金と仕入ルートを確立 | 最初にキャッシュと仕入の基盤を作ってから、消費者向けへ |
| **YouTube による広告費ゼロの集客** | 業界の裏側、車の選び方、失敗談を本人が語る | 「教育コンテンツ」が最強の広告。集客と信用が同時に積み上がる |
| **著書の刊行** | 業界問題の社会化の波に合わせて、「提言」を書籍化 | 発信の「タイミング」を捉え、一過性の注目を資産（本＝信用の固定化）に変えた |
| **BUDDICA DIRECT** | 現車を見ずに、LINE で相談し、オンラインで買える。全国配送 | 「中古車は見て買うもの」という常識を、透明な情報開示と保証で崩す |
| **制度設計（ノルマ・報酬）** | 売らせるための制度を捨て、顧客満足を軸に | 業界の悪習は「人」ではなく「制度」から変える |
| **社長の顔出し発信** | 危機も失敗も語る | 属人性はリスクだが、初期の信用構築では最強の武器 |

## 6-5 「業界を変える」型の抽出

中野の事例から、既存業界を顧客側から変える手順を抽出すると、次のようになります。

1. **業界の「儲けの構造」を、内側の人間として完全に理解する**（情報の非対称性、報酬制度、顧客が損している箇所）。
2. **自分の加担を認め、告白から始める**（信用の初期投資）。
3. **顧客が損している箇所を、無料の教育コンテンツで公開する**（YouTube、書籍）。業界からは敵視されるが、顧客と社会は味方になる。
4. **代替案を「自社の商品」として提示する**（透明な価格、オンライン完結、誠実な営業）。批判だけの人は消えるが、代替案がある人は残る。
5. **内部の制度を、顧客の利益と一致させる**（インセンティブ設計）。ここを変えないと、いずれ自社も同じ問題を起こす。
6. **外部の追い風（社会問題化、規制強化）を逃さない**。中野の場合は 2023年の業界不祥事。準備していた者だけが、追い風に乗れる。
7. **地方・小規模でも、デジタルで全国の顧客を持つ**。

## 6-6 中野モデルの課題（あなたが同じ道を行くなら）

- **資金**: 中古車は在庫ビジネスで、成長するほど運転資金が必要。中野自身も「成長のボトルネックは資金」と語っています。信用と集客ができても、**在庫・売掛を伴う事業では財務戦略（借入・出資）が同時に必要**です。
- **属人性**: 集客の大半が社長個人の発信に依存している状態から、「バディカだから買う」への移行が上場・拡大の鍵になります。
- **業界からの敵意**: 透明化は業界の既得権益を直接削るため、仕入先やパートナーとの関係に緊張が生まれます。小倉昌男のように「世論と顧客を味方につける」ことでしか乗り切れません。

- あなたの業界の「儲けの構造」を、顧客に全部見せたら、あなたの会社は生き残れるか。生き残れるなら、なぜ今見せていないのか。

## 7-3 戦略フレームワーク総覧 ― どの経営者が何を体現したか

経営理論は、実際には経営者の実践を後から整理したものです。理論と実例をセットで覚えると、応用が効きます。

### ドラッカー（企業の目的は「顧客の創造」。基本機能はマーケティングとイノベーション）
- マーケティング＝「売り込みを不要にすること」（顧客を理解し尽くす）。
- 体現者: 松下（水道哲学）、盛田（市場は作る）、ベゾス（顧客への執着）。

### ポーター（競争戦略）
- 3 つの基本戦略: コストリーダーシップ / 差別化 / 集中。中途半端（Stuck in the middle）が最悪。
- 「戦略とは何をしないかを決めること」。
- 体現者: コスト＝ウォルトン、IKEA、ケレハー。差別化＝スターバックス、Apple。集中＝サウスウエスト、ZARA（速さ）。

### ランチェスター戦略（弱者の戦略）
- 弱者は「局地戦・一騎打ち・接近戦・一点集中」。強者は「広域戦・確率戦・遠隔戦・総合力」。
- 体現者: ウォルトン（田舎）、ニトリ（北海道）、ティール（小さな市場を独占）、西野（芸人×絵本）。

### クリステンセン（破壊的イノベーション / ジョブ理論）
- 破壊的技術は、最初は「性能が低く、安く、既存顧客に見向きされない」ところから始まり、やがて主流を置き換える。
- 「顧客は製品を買うのではなく、片付けたい用事（ジョブ）のために製品を"雇う"」。
- 体現者: ソニー（トランジスタラジオ）、Netflix（DVD 郵送→配信）、Airbnb、メルカリ。

### ブルー・オーシャン戦略（キム & モボルニュ）
- 競争のない市場を作る。「取り除く・減らす・増やす・付け加える」の 4 アクション。
- 体現者: サウスウエスト（機内食を取り除く）、シルク・ドゥ・ソレイユ、宅急便、西野（絵本を無料化）。

### ハミルトン・ヘルマー『7 Powers』（持続的な競争優位の 7 源泉）
1. 規模の経済（ウォルマート、Amazon）
2. ネットワーク効果（楽天、メルカリ、Airbnb）
3. カウンターポジショニング（既存企業が真似すると自社を傷つける立場。Netflix vs ブロックバスター、バディカ vs 既存中古車店）
4. スイッチングコスト（Microsoft、SAP）
5. ブランド（Apple、スターバックス、パタゴニア）
6. 囲い込まれた資源（NVIDIA の CUDA エコシステム、ディズニーの IP）
7. プロセス・パワー（トヨタ生産方式、ZARA）

**中野優作のバディカは「カウンターポジショニング」の教科書的事例**です。既存の中古車店が透明化・ノルマ廃止を真似すると、自社の利益構造が壊れる。だから真似できない。

### ジム・コリンズ（ビジョナリーカンパニー）
- 針鼠（ハリネズミ）の概念: 「情熱を持てること × 世界一になれること × 経済的原動力」の重なり。
- 第 5 水準のリーダー: 謙虚さと不屈の意志。
- 弾み車（フライホイール）: 一押しで回らない、しかし押し続けると止まらなくなる。
- 体現者: 稲盛（謙虚さ＋意志）、ベゾス（弾み車）。

### エリック・リース（リーン・スタートアップ）/ PMF
- 構築→計測→学習のループ。MVP（最小限の製品）で仮説を検証する。
- PMF（プロダクト・マーケット・フィット）: 「顧客が製品を引っ張ってくれる」状態。PMF 前に拡大すると死ぬ。
- 体現者: 三木谷（仮説→実行→検証→仕組化）、チェスキー、南場（ピボット）。

### アンディ・グローブ（Intel）/ OKR
- 「パラノイアだけが生き残る」。戦略転換点を見逃すな。
- OKR（目標と主要な結果）: 野心的な目標と、測定可能な結果指標。
- 体現者: ゲイツ（インターネット転換）、ヘイスティングス（ストリーミング転換）。

### ジェフリー・ムーア（キャズム）
- 新製品は、イノベーター → アーリーアダプター → **キャズム（溝）** → アーリーマジョリティ → レイトマジョリティ。
- 溝を越えるには「特定のニッチで圧倒的な支持を得て、そこを橋頭堡にする」。
- 体現者: Tesla（ロードスター→Model S→Model 3）、西野（サロン会員→一般の映画観客）。

## 7-4 「矛盾する原則」の使い分け

優れた経営者は、対立する原則を局面で使い分けています。

| 対立 | いつ前者 | いつ後者 | 例 |
|------|---------|---------|-----|
| 長期思考 vs 短期の数字 | 投資判断・事業の方向 | 日々のオペレーション・資金繰り | 孫（300年ビジョン＋日次の数字）、永守 |
| 一点集中 vs 多角化 | PMF 前、資源が少ないとき | 主力が成熟し、キャッシュがあるとき | ジョブズ（復帰時に集中）→ Apple（後にサービス多角化） |
| トップダウン vs 現場主権 | 危機・転換点・文化の確立期 | 安定成長期・多店舗展開期 | 稲盛（JAL 再建は強力なトップダウン）、安田（平時は現場主権） |
| 標準化 vs 個店主義 | 品質が命の業態（食・安全） | 発見と体験が価値の業態 | マクドナルド vs ドン・キホーテ |
| 秘密主義 vs 透明性 | 技術・交渉・買収 | 顧客との関係・組織運営 | Apple（製品は秘密）vs バディカ（価格は透明） |
| 慎重 vs 大胆 | 会社が死ぬ賭け | 死なない賭け | 柳井（一勝九敗の「九敗で死なない」設計） |

**「どちらが正しいか」ではなく「いま自社はどの局面か」を見極めるのが経営者の仕事**です。

## 7-5 全員に共通する「失敗のパターン」

成功の型と同じくらい、失敗の型も共通しています。

1. **成功体験への固執**（フォードの T 型、本田の空冷、Netflix 前のブロックバスター）
   → 対策: 自社を食う事業を自分で始める（ヘイスティングス）。
2. **単一の後ろ盾・顧客への依存**（岩崎の政府、ジャック・マーと当局）
   → 対策: 売上・仕入・資金の集中度を定期的に測る。
3. **急拡大による文化の希薄化**（スターバックス 2008年、ユニクロ・ロンドン）
   → 対策: 拡大速度を「文化を伝えられる速度」に制限する。
4. **創業者の暴走・コンプライアンス**（ライブドア、マスクの発言、Zappos のホラクラシー混乱）
   → 対策: 「ダメ」と言える番頭を置く。
5. **後継者問題**（永守、多くのカリスマ経営者）
   → 対策: 本田・藤沢のように「引き際」を先に設計する。
6. **顧客への説明の順序を誤る**（Qwikster、西野の無料公開の炎上）
   → 対策: 戦略が正しくても、顧客が納得する物語と順番で出す。

## 8-1 まず自分を棚卸しする（1〜2 週間）

## 8-2 戦略を決める：山 → 土俵 → 打ち手

### ステップ 1: 山を決める（孫・似鳥）
30 年後、10 年後、3 年後、1 年後の「数字」と「状態」を書きます。

```
30年後: （例）__業界で、日本と__圏の顧客__万人に、__を提供している。売上__億円。
10年後: 上場している / していない。売上__億円、社員__人、海外売上比率__%。
3年後:  主力事業の PMF が完了。売上__億円、粗利率__%、顧客__人。
1年後:  最初の顧客 100 人（社）が熱狂している。月商__万円。
```

数字が書けないときは、似鳥の「30 年計画」の作り方を真似てください。**先進国・先進事例の「30 年前の姿」と「今の姿」を調べ、その差分を自分の業界に当てはめる**のです（タイムマシン経営）。

### ステップ 2: 土俵を選ぶ（ランチェスター・ティール・ウォルトン）
弱者は広い市場で戦ってはいけません。「勝てる狭い土俵」を選びます。

| 軸 | 問い | 例 |
|----|------|----|
| **地域** | 大手が「小さすぎる」と見ている地域は？ | ウォルトンの田舎、ニトリの北海道、バディカの香川 |
| **顧客層** | 大手が「面倒」「儲からない」と見ている顧客は？ | 楽天の中小出店者、ジャック・マーの中小企業、宅急便の個人 |
| **商品** | 業界が「儲からない」と切り捨てている商品・サービスは？ | 宅急便の小口、ユニクロのベーシック |
| **チャネル** | 業界が使っていないチャネルは？ | バディカの YouTube+LINE、テスラの直販、西野のクラファン |
| **価格帯** | 空いている価格帯は？（超高級 or 超低価格） | 西野の「ラグジュアリー」、IKEA の低価格 |

**土俵は一つだけ選びます。** 二つ選ぶと、どちらでも勝てません。

### ステップ 3: 「10 倍」を設計する（ティール・マスク）
選んだ土俵で、既存の選択肢より「10 倍良い」ものを定義します。2 倍では顧客は動きません。

- 10 倍安い（第一原理で原価を分解する。マスク）
- 10 倍速い（ZARA、宅急便の翌日配達）
- 10 倍簡単（メルカリの出品 3 分、バディカダイレクトの LINE 完結）
- 10 倍透明（バディカ）
- 10 倍楽しい・美しい（Apple、ディズニー、ドンキ）

「10 倍」が一つも書けないなら、土俵の選択に戻ります。

### ステップ 4: フライホイールを描く（ベゾス）
自己強化するループを 1 枚の図にします。例（サービス業の一般形）:

```
発信で信用が貯まる → 顧客が来る → 誠実に対応して満足させる
   ↑                                        ↓
紹介・口コミ・レビューが増える  ←  顧客が「共犯者」（応援者）になる
```

**どの一点を押せば全体が回り始めるか**（多くの場合「最初の 100 人の熱狂」）を特定し、そこに全資源を投入します。

### ステップ 5: 「やらないこと」と「撤退基準」を決める（ポーター・ケレハー・藤田）
- やらないこと 3 つ（例: 値引き営業はしない、大手向けの受託はしない、店舗は増やさない）
- 撤退基準（例: 12 か月で月商__万円に届かなければ、この事業は畳む）
- 「9 敗」の上限（例: 新規事業 1 件あたりの損失上限__万円。会社の現預金の__%まで）

## 8-3 集客：4 層モデルと 90 日プラン

西野・中野・チェスキー・ウォルトンに共通する集客の構造を、4 層に一般化します。**広告は最後**です。

### 4 層モデル

| 層 | 目的 | 手段 | 指標 | 参考 |
|----|------|------|------|------|
| **第 1 層: 発信（無料）** | 認知ではなく「信用」を作る | YouTube / 音声 / ブログ / SNS / 書籍。**業界の裏側・顧客が損している箇所・自分の失敗**を語る。売り込まない | 毎日続いているか、コメント・保存・シェア | 西野（毎日長文）、中野（YouTube） |
| **第 2 層: 最初の 100 人（手作業）** | 熱狂する初期顧客を作る | 一人ひとりに会う、家に行く、電話で 1 時間話す。**スケールしないことをやる** | NPS（推奨度）、紹介率、リピート率 | チェスキー、ウォルトン（現場歩き） |
| **第 3 層: コミュニティ（有料・継続）** | 安定収益と、労働力・宣伝者の確保 | 月額会員、会員限定イベント、制作過程の公開、「応援シロ」の提供 | 会員数、継続率、会員からの紹介数 | 西野（サロン）、スターバックス（サードプレイス） |
| **第 4 層: 増幅（イベント・広告・PR）** | 第 1〜3 層で証明された価値を、一気に外へ | 発売イベント、クラファン、PR、テレビ CM、広告 | CAC（顧客獲得単価）と LTV（顧客生涯価値）の比 | メルカリ（CM）、ジャック・マー（独身の日） |

**順番を守ってください。** 第 1〜2 層を飛ばして第 4 層（広告）にお金を使うと、「知られているが応援されていない」状態になり、広告を止めた瞬間に顧客が消えます。

### コンテンツの型（第 1 層で何を語るか）
1. **業界の裏側**（なぜその価格なのか、なぜそう言われるのか）
2. **顧客が損しないための知識**（選び方、見分け方、聞くべき質問）
3. **自分の失敗と学び**（信用は完璧さではなく、正直さから生まれる）
4. **作っている途中**（新商品の試作、悩み、ボツ案 → 応援シロ）
5. **顧客の物語**（顧客を主役にする）

「売り込み」は 10 本に 1 本以下。**教育コンテンツが最強の広告**です（中野）。

### 90 日プラン（テンプレート）

```
Day 1-30:  発信の基盤
  - 発信媒体を 1 つ選ぶ（顧客がいる場所。BtoC は YouTube/Instagram/TikTok、BtoB は note/X/LinkedIn/セミナー）
  - 「業界の裏側」「顧客が損しないための知識」を 20 本、先に書き溜める
  - 毎日 1 本、90 日間止めない
  - 目標: 発信を見て「相談したい」と言ってきた人 10 人

Day 31-60: 最初の 100 人
  - 相談してきた人全員に、直接会う（オンライン可）。売らずに 1 時間聞く
  - 10 人に売る。売った後の体験を「11 つ星」に近づける（手書きの手紙、想定外のフォロー）
  - 買った人の声を（許可を得て）発信に戻す
  - 目標: 有料顧客 10 人、うち 3 人が誰かを紹介

Day 61-90: 型を作る
  - 100 人に届くまで、「相談 → 購入 → 紹介」の流れを 1 枚のフローにする
  - 紹介が生まれた理由を分析し、再現できる形（紹介特典、紹介のタイミング）にする
  - コミュニティ（第 3 層）の設計に着手: 月額いくらで、何を提供するか
  - 目標: 累計顧客 30〜100 人、紹介経由比率 30% 以上、CAC（自分の時間を含む）の把握
```

### 集客の KPI（最小セット）
- 発信の継続日数（止めたら全部ゼロに戻る）
- 相談数 → 成約数 → 紹介数（各段階の転換率）
- リピート率 / 継続率
- 紹介経由比率（30% を超えると、フライホイールが回り始めた証拠）
- CAC と LTV の比（LTV ÷ CAC が 3 以上で第 4 層の広告投資を検討）

## 8-4 業界を変える：顧客側に立つ「逆張り」の設計

小倉昌男、稲盛（第二電電）、ジャック・マー、ヘイスティングス、中野優作に共通する「業界変革」の手順です。

### ステップ 1: 業界の「歪み」を特定する
業界が儲かっている理由の中で、**顧客が損している箇所**を見つけます。典型は 5 つ。

| 歪みの型 | 中身 | 変えた例 |
|---------|------|---------|
| **情報の非対称性** | 顧客が知らないから高く売れる | バディカ（中古車）、ライフネット生命（保険料の内訳開示） |
| **報酬・評価制度** | 売る側の報酬が、顧客の利益と一致していない | バディカ（ノルマ・インセンティブ依存からの脱却）、テスラ（直販） |
| **価格・手数料** | 中間マージンや慣習的な手数料が高い | 楽天（出店料）、タオバオ（無料）、Amazon（「あなたの利益率は私の機会」） |
| **体験・手間** | 顧客が我慢している不便を、業界が「当たり前」と思っている | 宅急便（翌日配達）、メルカリ（出品 3 分）、Netflix（延滞料なし） |
| **流通・チャネル** | 既存のチャネルに縛られている | ソニー（自社ブランドで海外）、西野（クラファン）、ニトリ（製造物流IT小売） |

### ステップ 2: 「カウンターポジショニング」を作る
既存企業が真似すると自社を傷つける立場を取ります。

- バディカの透明化 → 既存店が真似すると、非対称性で稼いでいた利益が消える
- Netflix の定額 → ブロックバスターが真似すると、延滞料収入が消える
- **「大手が真似できない理由」を 1 行で言えるか**が判定基準。言えなければ、大手が真似した瞬間に負けます。

### ステップ 3: 「大義」と「味方」を先に作る
業界を変えようとすると、必ず業界から攻撃されます。稲盛は「国民の通信料金を下げる」大義でトヨタ・ソニーを味方にし、小倉は運輸省と戦いながら世論を味方にしました。中野は顧客と社会を味方にしました。

- 大義を 1 文で書く（「__業界の__を、顧客のために__する」）
- 味方のリスト: 顧客、メディア、業界内の良心的な事業者、規制当局の改革派、投資家
- **堀江貴文の教訓**: 敵を作りすぎると、いざというとき誰も助けてくれない。業界の中に必ず味方を作る。

### ステップ 4: 「告白」から始める（中野）
あなた自身が業界の内側にいたなら、まず自分の加担を認めます。これが最も強い信用の初期投資になり、「お前も同じだ」という反論を封じます。

### ステップ 5: 代替案を「商品」として出す
批判だけでは変わりません。代替案（透明な価格表、新しい契約形態、オンライン完結、成果報酬）を、自社の商品として出し、それが売れることを証明します。

### ステップ 6: 内部の制度を、顧客の利益と一致させる
- 評価制度: 売上ではなく、顧客満足・紹介率・継続率を主指標に
- 報酬制度: 個人の売上連動を弱め、チーム・会社業績＋顧客指標に
- 情報公開: 社内で隠していた数字（原価、粗利）を、可能な範囲で顧客にも社員にも見せる

**ここを変えないと、いずれ自社も同じ問題を起こします。**

### ステップ 7: 追い風を待ち、逃さない
業界の不祥事、規制の変更、技術の変化、世代交代。追い風は必ず来ますが、**来たときに準備ができている者だけが乗れます**。中野の 2023 年は、2017 年からの 6 年の準備があったから機能しました。

### 変革のリスク管理
- **資金**: 変革は先行投資です。ランウェイ（資金が尽きるまでの月数）を毎週見る（ナイト）。
- **法務**: 業界慣行を破るとき、法律・規制に触れていないかを必ず専門家に確認（堀江）。
- **属人性**: 変革者本人が倒れると止まる状態から、早く「会社の型」へ（第 8-6 節の上場準備と同じ課題）。

## 8-5 海外へのアプローチ：3 段階と市場選定

### まず「いつ出るか」を決める 2 つの型

| 型 | 内容 | 向いている事業 | 例 |
|----|------|--------------|-----|
| **国内で勝ってから型** | 国内で圧倒的な地位と現金を作ってから、海外へ | 店舗・在庫・物流を伴う事業、ローカル規制の強い事業 | ユニクロ、ニトリ、ドンキ、ニデック（M&A） |
| **最初から世界型（Born Global）** | 創業初期から海外前提でブランド・組織を作る | ソフトウェア、IP・コンテンツ、ネットワーク効果が国境を越える事業 | ソニー（社名変更・盛田渡米）、メルカリ、西野（ミュージカル） |

判定の問い: **あなたの事業の「ネットワーク効果」や「規模の経済」は、国境を越えて働くか？** 越えるなら早く、越えないなら国内で現金を作ってから。

### 海外進出の 3 段階

```
段階 1: 日本にいながら海外の顧客を取る（インバウンド・越境）
  - 訪日客に売る（ドンキ、百貨店、体験サービス）
  - 越境 EC（Amazon 海外、Shopify、Etsy）
  - 英語のコンテンツ・SNS・YouTube（西野のように、まず「知られる」）
  - コスト: 低。学べること: どの国の誰が反応するか

段階 2: テスト都市を 1 つ選び、小さく出る
  - 世界都市の「旗艦店」でブランドを作る（柳井: 上海・NY・ロンドン）
  - または、文化的距離が近い市場（台湾・シンガポール・タイ）で運営を学ぶ（ドンキ）
  - 創業者または No.2 が「住む」（盛田の NY 移住）。出張では分からない
  - 現地の一流パートナーと組む（西野: ブロードウェイの作曲家。ナイト: 日本の商社）
  - コスト: 中。学べること: 商品・価格・売り方のどこを変えるべきか

段階 3: 現地法人・現地チーム・現地生産
  - 現地の人が経営する（本社の日本人が指示する体制は必ず失敗する）
  - 「グローバル・ローカライゼーション」: 標準と現地化の境界を明確にする
  - 組織 OS の切り替え（三木谷: 英語公用語化。Netflix: 190 か国同時）
  - コスト: 高。ここで失敗するとダメージが大きい（ウォルマートのドイツ、ユニクロ初期のロンドン、楽天の海外 EC）
```

### 市場選定の 5 つの軸

| 軸 | 問い | 補足 |
|----|------|------|
| **市場規模と成長率** | 10 年後に大きい市場か | 米国（最大）、東南アジア・インド（成長）、中東（資金） |
| **文化的・地理的距離** | 日本の商品・サービスの「意味」が伝わるか | 台湾・タイ・シンガポールは日本ブランドへの信頼が高く、最初のテストに向く |
| **競合の強さ** | 現地に強いプレイヤーがいるか | 空いている市場を選ぶ（ランチェスター） |
| **規制・法務** | 免許、外資規制、データ規制 | 早い段階で現地の弁護士に確認 |
| **「日本の当たり前」が価値になるか** | 日本では普通だが、海外では希少なものは？ | 品質・清潔・接客・正確さ・安全・アニメや食などの文化資産 |

### 海外で失敗する典型と対策

| 失敗 | 例 | 対策 |
|------|-----|------|
| 日本の型をそのまま持ち込む | ウォルマートのドイツ撤退、ユニクロ・ロンドン初期 | 段階 2 で「何を変えるか」を学んでから拡大 |
| 本社が現地を遠隔操作 | 多くの日本企業の海外子会社 | 現地トップに権限と報酬を渡す（安田の「現場主権」の海外版） |
| ブランドを売らずに OEM で楽をする | 盛田が断った 10 万台 | 短期の売上より、自社ブランドの資産を優先 |
| 名前・言葉が通じない | 発音できない社名 | ソニーの社名変更、西野の「プペル→Binny」 |
| 資金が続かない | 海外は黒字化まで国内の 2〜3 倍かかる | 国内のキャッシュカウを確保してから（藤田の二層構造） |

## 8-6 上場（IPO）への道：目的、市場、基準、タイムライン

### 最初に決めること：なぜ上場するのか
渋沢の合本主義に戻ります。上場とは「事業を社会のものにし、多くの人の資本で成長する」ことです。目的が「創業者が儲かる」だけなら、M&A（売却）のほうが早くて確実です。パタゴニアのように「上場しない」戦略もあります。

| 上場のメリット | 上場のコスト・デメリット |
|--------------|----------------------|
| 資金調達（増資、社債） | 上場準備に 2〜4 年、数千万〜億単位の費用 |
| 信用（採用、取引、海外展開で効く） | 四半期ごとの開示、株主対応、短期業績への圧力 |
| 株式を通貨にした M&A | 内部統制・監査・ガバナンスの負担 |
| 従業員のストックオプションの現金化 | 創業者の持株比率低下、買収リスク |
| 創業者・投資家の出口 | 経営の自由度低下（パタゴニアが避けた理由） |

**上場しない場合の選択肢**: 非上場のまま成長（サントリー、竹中工務店、ロッテ）、事業売却、資本業務提携、TOKYO PRO Market（後述）。

### 日本の市場区分と主な形式基準（新規上場時）

以下は東京証券取引所の一般的な形式基準の概要です。**基準は改定されます。必ず日本取引所グループ（JPX）の最新の上場審査基準と、主幹事証券・監査法人の助言で確認してください。**

| 項目 | グロース | スタンダード | プライム |
|------|---------|------------|---------|
| コンセプト | 高い成長可能性を持つ企業 | 一定の時価総額・流動性と基本的なガバナンス | グローバルな投資家との建設的な対話を中心に据えた企業 |
| 株主数 | 150 人以上 | 400 人以上 | 800 人以上 |
| 流通株式時価総額 | 5 億円以上 | 10 億円以上 | 100 億円以上 |
| 流通株式比率 | 25% 以上 | 25% 以上 | 35% 以上 |
| 時価総額 | 規定なし（下記の維持基準に注意） | 規定なし | 250 億円以上 |
| 利益・売上 | 規定なし（赤字でも可、成長性を審査） | 最近 1 年間の利益 1 億円以上 | 最近 2 年間の利益合計 25 億円以上、または売上 100 億円以上かつ時価総額 1,000 億円以上 |
| 事業継続年数 | 1 年以上 | 3 年以上 | 3 年以上 |
| 純資産 | 規定なし | 正であること | 50 億円以上 |

**グロース市場の重要な変更（2025 年発表）**: 東証はグロース市場の上場維持基準を厳格化し、これまでの「上場 10 年経過後に時価総額 40 億円以上」を「**上場 5 年経過後に時価総額 100 億円以上**」に引き上げました（2030 年 3 月以降に適用）。新規上場時の形式基準は据え置きですが、審査では「5 年で 100 億円を超える成長性」が実質的に問われるようになります。つまり、**グロース上場を目指すなら、上場時点で「5 年で時価総額 100 億円」に届く事業計画が必要**です。

**TOKYO PRO Market**: プロ投資家向けの市場で、株主数や利益の形式基準がなく、J-Adviser（東証が認定した支援会社）の審査で上場できます。一般市場への「予行演習」として使う中小企業が増えています。地方企業や、まず「上場企業」の信用を採用・取引で使いたい企業に向きます。

### 上場審査で見られる「実質基準」
形式基準を満たしても、以下の「実質基準」で落ちる企業が多数あります。

1. **企業の継続性・収益性**: 事業計画の合理性、特定顧客への依存（岩崎の教訓）
2. **企業経営の健全性**: 関連当事者取引（社長の親族会社との取引など）の解消、反社会的勢力の排除
3. **コーポレート・ガバナンス・内部管理体制の有効性**: 取締役会、監査役（会）または監査等委員会、内部監査、予算実績管理、J-SOX 対応
4. **企業内容等の開示の適正性**: 適時開示体制、会計処理の適正さ
5. **その他公益・投資者保護**: 労務（未払残業、36 協定）、許認可、訴訟

**堀江貴文の章の教訓はここに直結します。** 攻めの経営者ほど、守り（CFO・監査役・顧問弁護士）に自分より厳しい人を置く必要があります。

### タイムライン（N 期 = 上場申請期）

```
N-4 期以前: 準備の準備
  - 「なぜ上場するか」を役員全員で言語化
  - 監査法人によるショートレビュー（上場に向けた課題の洗い出し）
  - 事業の「上場に耐える型」への転換: 属人的な営業・集客を仕組みへ、社長の個人口座と会社の分離、親族取引の解消
  - CFO 候補の採用（最も難しく、最も重要な採用）

N-3 期: 体制整備
  - 監査法人と契約（N-2 期から監査証明が必要なため、N-3 期中に契約が望ましい）
  - 主幹事証券会社の選定
  - 規程類の整備（職務権限、稟議、経費、労務）
  - 月次決算を翌月 10 営業日以内に締める体制
  - 資本政策の設計（誰にどれだけ株を持たせるか。**一度渡した株は戻らない**。ここは専門家と）

N-2 期: 監査初年度（直前々期）
  - 会計監査の適用、内部統制（J-SOX）の文書化開始
  - 取締役会・監査役会の実質的な運営（議事録、月次報告）
  - 予算実績管理の精度（予算との乖離が大きいと審査で問題になる）
  - 労務監査、許認可の確認

N-1 期: 直前期
  - 内部監査の運用、内部統制の運用評価
  - 証券会社による引受審査
  - 上場申請書類（Ⅰの部、Ⅱの部）のドラフト
  - 成長ストーリー（エクイティ・ストーリー）の作成: 投資家に「5 年で時価総額 100 億円」を信じさせる物語

N 期: 申請期
  - 東証への上場申請、審査（グロースで約 2〜3 か月）
  - 承認 → ロードショー（機関投資家への説明）→ 仮条件決定 → ブックビルディング → 公開価格決定 → 上場
```

**費用の目安**: 監査報酬、証券会社の引受手数料（調達額の数%）、印刷・IR・システム費用などで、準備期間を通じて数千万円〜数億円。上場後も年間で相応の維持コストがかかります。

### 資金調達の順序（上場前）

| 段階 | 資金源 | 注意 |
|------|--------|------|
| 創業〜PMF 前 | 自己資金、創業融資（日本政策金融公庫）、補助金、クラファン（西野型） | エクイティ（株）を安易に渡さない。この時期の株は最も高くつく |
| PMF 後〜拡大 | エンジェル、VC のシード〜シリーズ A、銀行融資 | VC は「上場か売却」を求める。その覚悟がないなら借入で |
| 拡大期 | シリーズ B 以降、事業会社からの出資（出雲の伊藤忠型）、社債 | 事業シナジーのある大企業 1 社の出資が、信用を一気に上げる |
| 上場前 | 主幹事証券・機関投資家 | 直前期の株価と公開価格の整合性が審査で見られる |

**在庫・売掛を伴う事業（中野の課題）**: 成長するほど運転資金が必要になるため、早い段階で銀行との関係（メインバンク、当座貸越枠、ABL）を作る。エクイティだけで運転資金を賄うのは希薄化が大きすぎます。

### 上場に向けて「属人性」を外す（西野・中野の課題への回答）
創業者個人の発信力で成長した会社が上場を目指すとき、審査で最も問われるのが「社長が倒れたら会社はどうなるか」です。

1. **集客の分散**: 社長のチャンネルから、会社・ブランド・社員のチャンネルへ徐々に移す（社員の顔出し、顧客の声）
2. **ナレッジの文書化**: 社長の判断基準を「フィロソフィ」「原則」として書く（稲盛、ダリオ）
3. **No.2 と経営チーム**: 藤沢武夫、ティム・クック、盛田に対する井深。得手を分ける
4. **意思決定の会議体**: 社長の独断から、取締役会・経営会議の決議へ

## 8-8 経営者のマインド・習慣チェックリスト

本書に登場した経営者の「日々の習慣」を、実行可能な形にしました。全部やる必要はありません。**3 つ選んで 90 日続けてください。**

### 思考の習慣
- [ ] 毎朝、「登る山」（30 年・10 年・3 年・1 年の目標）を読み返す（孫・似鳥）
- [ ] 判断に迷ったら「動機善なりや、私心なかりしか」と問う（稲盛）

- [ ] 「業界ではこうだ」ではなく、原価と物理から考える（マスク）
- [ ] 週に 1 回、「自社を食う技術・モデルは何か」を考える（ヘイスティングス・ゲイツ）

### 行動の習慣
- [ ] 毎日、顧客のために何かを発信する（西野・中野）。売り込みは 10 本に 1 本以下
- [ ] 週に 1 回、顧客に直接会う、または現場に立つ（ウォルトン・松下・安田）
- [ ] 月に 1 回、競合・先進事例を見に行く（ウォルトン・似鳥）
- [ ] 失敗したら、24 時間以内に「原則」として書き残す（ダリオ）
- [ ] 「すぐやる、必ずやる、出来るまでやる」（永守）

### 数字の習慣
- [ ] 現預金とランウェイ（資金が尽きるまでの月数）を毎週見る（ナイト）
- [ ] 売上・粗利・顧客数・紹介率を、日次または週次で見る（永守・孫）
- [ ] 上位 1 社・1 チャネルへの依存度を月次で見る（岩崎の教訓）
- [ ] 新規事業の「撤退基準」と「9 敗の上限」を四半期ごとに確認する（藤田・柳井）

### 人の習慣
- [ ] 自分の「不得手」を担う相棒を探し続ける（本田・藤沢）
- [ ] 「ダメです」と言える人を、意識的に近くに置く（堀江の教訓）

### 正直の習慣

- [ ] 自分の過去の失敗・加担を、隠さず語る（中野・南場・柳井）
- [ ] 隠している数字があれば、「なぜ隠しているか」を自問する（ダリオ・中野）

## 付録 B: 用語集

| 用語 | 意味 |
|------|------|
| **PMF（プロダクト・マーケット・フィット）** | 製品が市場に受け入れられ、顧客が製品を「引っ張る」状態。これ以前の拡大は危険 |
| **CAC / LTV** | 顧客獲得単価 / 顧客生涯価値。LTV ÷ CAC が 3 以上が広告投資の目安 |
| **ランウェイ** | 現在の現預金と月次の赤字額から計算した、資金が尽きるまでの月数 |
| **フライホイール** | 自己強化するループ。一押しでは回らないが、押し続けると止まらなくなる |
| **カウンターポジショニング** | 既存企業が真似すると自社を傷つける立場（7 Powers の一つ） |
| **SPA** | 製造小売業。企画・製造・販売を一貫して行うモデル（ユニクロ、ZARA、ニトリ） |
| **タイムマシン経営** | 先進市場で成功したモデルを、時間差で別の市場に持ち込む（孫正義） |
| **エスクロー** | 第三者が代金を預かり、取引完了後に売り手へ渡す仕組み。マーケットプレイスの信頼インフラ |
| **エクイティ / デット** | 株式による資金調達 / 借入による資金調達 |
| **資本政策** | 誰にどれだけ株式を持たせるかの計画。上場前に最も慎重に設計すべきもの |
| **N 期・N-1 期・N-2 期** | 上場申請期・直前期・直前々期。直前 2 期の監査証明が必要 |
| **J-SOX** | 金融商品取引法にもとづく内部統制報告制度 |
| **流通株式** | 大株主・役員などの固定的な株主が保有する株式を除いた、市場で流通しうる株式 |
| **TOKYO PRO Market** | プロ投資家向けの市場。形式基準が緩く、J-Adviser の審査で上場できる |
| **エクイティ・ストーリー** | 投資家に対する成長の物語。上場時の株価を左右する |
| **応援シロ** | 西野亮廣の用語。人が参加・応援したくなる余白 |
| **信用経済** | お金ではなく信用が資本になるという考え。クラファンやコミュニティの基盤 |
