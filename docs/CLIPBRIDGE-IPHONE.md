# ClipBridge を iPhone から使う

[`CLIPBRIDGE.md`](CLIPBRIDGE.md) のツールを、iPhone で毎回ブラウザを開かずに使うための手順です。
iPhone に元から入っている **「ショートカット」アプリ**だけで作れます。
App Store から何かを入れる必要はありません。

先に正直に書いておくと、**PC のキーボードで iPhone の他のアプリに直接タイプすることは、
どの方法でもできません。** Apple が Mac 以外との連携を閉じているためです。
ここでできるのは「PC で打った文字を iPhone のクリップボードに入れる」までで、
そこから先は貼り付けです。それでも、ブラウザを開いて「コピー」を押す手間が無くなるので、
体感はかなり違います。

## できるようになること

| 操作 | 結果 |
|---|---|
| iPhone のどのアプリでも、文字を選んで **共有 → 「PC へ送る」** | その文字が PC のクリップボードに入る。PC で Ctrl+V するだけ |
| iPhone の背面を **2回タップ**（背面タップに割り当てた場合） | PC でコピーした文字が iPhone のクリップボードに入る。あとは貼り付け |
| 同じく背面タップやホーム画面のアイコンから **「PC で打った文字を取り込む」** | PC の ClipBridge 画面で「送る」した文字が iPhone のクリップボードに入る |

## 準備

1. PC で `npm run clipbridge` を起動し、表示された行を控える。

   ```
   スマホで開く: http://192.168.1.23:8787/?t=3f9a1c7e2b904d15
               : http://x1yoga.local:8787/?t=3f9a1c7e2b904d15
   合言葉（?t=）: 3f9a1c7e2b904d15
   ```

   以下では **`x1yoga.local`** の部分と **`3f9a1c7e2b904d15`** の部分を、自分のものに読み替えてください。
   `.local` の方を使うのは、Wi-Fi ルータが IP アドレスを変えても壊れないようにするためです。
   もし `.local` でつながらない場合だけ、IP アドレスの方を使ってください。

2. iPhone を PC と同じ Wi-Fi につなぐ。

3. 動作確認として、iPhone の Safari で「スマホで開く」の URL を開き、右上が「● 接続中」になることを確かめる。
   ここで開けなければ、ショートカットも動きません（PC のファイアウォールで「プライベート ネットワーク」を許可しているか確認）。

## ショートカット 1: 「PC へ送る」（共有シート用）

iPhone のどのアプリからでも、選んだ文字を PC のクリップボードに入れます。

1. 「ショートカット」アプリを開き、右上の **＋** で新規作成。
2. 上部の名前を **「PC へ送る」** にする。
3. 右上の **ⓘ（詳細）** を開き、**「共有シートに表示」をオン**にして閉じる。
   先頭に「ショートカットの入力を受け取る」というブロックが自動で入ります。
4. そのブロックをタップして、受け取る種類を **「テキスト」と「URL」** だけにする。
   **「入力がない場合」を「クリップボードを取得」**にする。
   これで、共有からでなく直接起動したときは、iPhone のクリップボードの中身が送られます。
5. アクションを追加: **「URL の内容を取得」**（検索欄に「URL」と入れると出ます）。
   - URL: `http://x1yoga.local:8787/api/send?t=3f9a1c7e2b904d15`
   - 「詳細を表示」を開く
   - 方法: **POST**
   - 本文を要求: **JSON**
   - 「新規フィールドを追加」→ **テキスト**、キー `text`、値は **「ショートカットの入力」**（変数を選ぶ）
   - もう一つ「新規フィールドを追加」→ **テキスト**、キー `from`、値 `phone`
6. アクションを追加: **「通知を表示」**。本文に「PC に送りました」。
7. 右上の「完了」。

使い方: メモやメッセージで文字を選択 → **共有** → 一覧から **「PC へ送る」**。
初回だけ「x1yoga.local への接続を許可しますか」と「ローカルネットワーク」の確認が出るので、**許可**します。
PC 側は Ctrl+V するだけで貼り付けられます。

## ショートカット 2: 「PC のクリップボードを取り込む」

PC で Ctrl+C した文字を、iPhone のクリップボードに入れます。

1. **＋** で新規作成。名前を **「PC のクリップボードを取り込む」**。
2. アクション **「URL の内容を取得」**。
   - URL: `http://x1yoga.local:8787/api/clipboard?t=3f9a1c7e2b904d15`
   - 方法: **GET**（既定のまま）
3. アクション **「クリップボードにコピー」**。入力は自動で「URL の内容」になります。
4. アクション **「通知を表示」**。本文に「URL の内容」の変数を置くと、取り込んだ文字が通知に出て確認できます。
5. 「完了」。

## ショートカット 3: 「PC で打った文字を取り込む」

PC の ClipBridge 画面で打って「送る」（Ctrl+Enter）した文字を、iPhone のクリップボードに入れます。
「PC のキーボードで打った文章を iPhone に持っていく」用途はこれが一番速いです。

ショートカット 2 と同じ作りで、URL だけ変えます。

- URL: `http://x1yoga.local:8787/api/latest?t=3f9a1c7e2b904d15&from=pc`

## 背面タップに割り当てる（おすすめ）

ショートカット 2 か 3 を、iPhone の背面をトントンと叩くだけで動くようにします。

設定 → アクセシビリティ → タッチ → **背面タップ** → ダブルタップ（またはトリプルタップ）→
一覧の下の方にある「ショートカット」から選ぶ。

PC で Ctrl+C → iPhone の背面を2回叩く → 貼り付け、という流れになります。

## ホーム画面にアイコンを置く

- ショートカットは、一覧で長押し → 「詳細」→ **「ホーム画面に追加」**。
- ClipBridge の画面そのものも、Safari で開いて **共有 → 「ホーム画面に追加」** しておくと、
  アプリのように1タップで開けます。合言葉は固定なので、このブックマークは壊れません。

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| 「サーバに接続できません」 | PC で `npm run clipbridge` が動いているか。iPhone が同じ Wi-Fi か。`.local` がダメなら IP アドレスの URL に変える |
| Safari では開けるのにショートカットだけ失敗する | 初回の「接続を許可しますか」で「許可しない」を押した可能性。設定 → ショートカット → 詳細 → 「信頼されていないショートカットを許可」ではなく、**設定 → プライバシーとセキュリティ → ローカルネットワーク → ショートカット** をオン |
| 「PC へ送る」で PC に貼り付けられない | PC の ClipBridge 画面に文字は届いているか。届いていれば PC 側のクリップボード書き込みの問題。画面の「コピー」ボタンで代用できる |
| 合言葉を変えたい | PC で `npm run clipbridge -- --new-token`。3つのショートカットの `?t=` も書き換える |
| 空の文字が返ってくる | PC のクリップボードに入っているのが画像やファイルのとき。文字だけ対応 |
