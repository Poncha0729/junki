# 駅データの増やし方

駅の情報は [`src/lib/stations.ts`](../src/lib/stations.ts) の1ファイルにまとまっています。
データベースは使っていないので、このファイルを編集して `git push` すれば反映されます。

---

## 大原則：数字は出典が取れたものだけ載せる

家賃相場のように**変動し、判断に影響する数字**は、出典が確認できたものだけ登録してください。

- 出典が取れた → `avgRent` に入れて、`rentSource` に出所を書く
- 出典が取れない → **`avgRent` を書かない**（`undefined` のままにする）

未登録の駅は、画面上で「この駅の家賃相場はまだ登録されていません」と表示され、
調べるためのリンクが出ます。**推測値で埋めるより、空である方が安全です。**

> 現在 `avgRent` が入っているのは渋谷だけで、これはリポジトリに元から入っていた
> サンプル値です。実測に基づくものではないため `rentSource` にその旨を明記してあります。
> 実データに差し替える際は、下の手順で出典付きに置き換えてください。

## 駅を1つ追加する

`src/lib/stations.ts` の `stations` に、キーを `slug` と同じ文字列にして追加します。

```ts
  nakano: {
    slug: 'nakano',
    name: { en: 'Nakano', ja: '中野' },
    lines: ['JR中央線', 'JR総武線', '東京メトロ東西線'],
    ward: '中野区',
    coords: { lat: 35.7056, lng: 139.6659 },
    exits: ['北口', '南口'],
    pros: [
      '中央線快速で新宿まで1駅',
      '商店街が長く、日常の買い物先が多い',
    ],
    cons: [
      '朝の中央線快速の混雑が激しい',
    ],
    // 家賃は出典が取れてから追加する
    photos: [],
    lastUpdated: '2026-09-19',
  },
```

追加すると、トップページの一覧と検索、`/stations/nakano` の詳細ページが自動で増えます。
ルーティングやリンクを別途書く必要はありません。

### 各項目の書き方

| 項目 | 内容 | 注意 |
|---|---|---|
| `slug` | URL に使う英小文字 | キーと同じ文字列にする |
| `name` | 日本語名・英語名 | 「駅」は付けない（表示側で付けます） |
| `lines` | 乗り入れ路線 | 正式名称で。検索対象になります |
| `ward` | 所在する区・市 | 検索対象になります |
| `coords` | 地図の中心座標 | 厳密な駅舎の位置でなくてよい（下記参照） |
| `exits` | 主な出口名 | 分かるものだけでよい |
| `pros` / `cons` | 特徴と注意点 | **具体的な店名や徒歩分数は出典なしに書かない** |
| `avgRent` | 家賃相場（円） | 出典が取れた場合のみ |
| `rentSource` | 家賃の出所 | `avgRent` があるときは必須 |
| `photos` | 写真のパス | 空配列なら代替表示になる |
| `lastUpdated` | 更新日 | `YYYY-MM-DD` |

### 座標の調べ方

1. https://www.openstreetmap.org/ で駅名を検索する
2. 駅の位置を右クリック →「ここの地物を表示」
3. URL の `#map=17/35.7056/139.6659` の後ろ2つが `lat` / `lng`

## 家賃相場を登録する

出典を確認したうえで、金額（円／月）と出所をセットで書きます。

```ts
    avgRent: { studio: 98000, oneK: 112000, oneLdk: 165000 },
    rentSource: {
      label: 'SUUMO 家賃相場',
      url: 'https://suumo.jp/chintai/soba/tokyo/ensen/',
      retrievedAt: '2026-09-19',
    },
```

画面には金額の横に**出典名と取得日**が表示されます。
数か月経った数字は古くなるので、`retrievedAt` を見て更新してください。

## 写真を追加する

1. `public/images/stations/<slug>/` を作り、画像を置く
2. `photos` にパスを列挙する（`public` は書かない）

```ts
    photos: [
      '/images/stations/nakano/hero.jpg',   // 1枚目 = ページ上部の大きな画像
      '/images/stations/nakano/shotengai.jpg',
    ],
```

`photos` が空のあいだは、壊れた画像ではなく代替表示が出ます。

> **権利に注意してください。** 他サイトの写真を無断で持ってこないこと。
> 自分で撮影したものか、商用利用可のライセンスが明示された素材を使ってください。

